# A~F 六类题型的翻译信号

研赛六题**不是按难度排序**，而是按命题领域并置。翻译阶段的首要任务不是读懂每个公式，而是**认出这是哪一族题**，因为题型族决定了后续模型候选池与验证方式。以下信号表按 2020—2025 年（第十七至二十二届）36 道真题归纳。

## 通用高频信号（六题通用）

| 信号表述 | 真实含义 | 翻译动作 |
|---|---|---|
| "结合附件数据" / "附件中给出" | 数据是评分基础，不看数据必错 | 逐份附件登记：字段、量纲、时间范围、样本量 |
| "请给出……的方案/策略" | 要交付**决策**而非单纯预测 | 交付要求必须落到"可执行的方案表" |
| "分析其影响因素" | 要求敏感性/归因，不是罗列 | 预留灵敏度分析章节 |
| "建立……模型" | 至少一个模型要完整闭环（假设→建立→求解→检验） | 在依赖图中标出哪一问是主模型 |
| "评价/判断/排名" | 评价类任务，必须有指标体系与权重依据 | 权重来源要能自证 |
| **补充说明 / 更正说明 / 附录** | **口径变更，优先级高于主赛题** | 单独登记并覆盖主赛题对应条款 |

## A 题信号

**典型形态**：信号/芯片/物理机理建模。历年样本：2020 芯片相噪算法设计（华为题）、2021 相关矩阵组的低复杂度计算和存储建模（华为题）、2022 移动场景超分辨定位问题（华为题）、2023 WLAN 网络信道接入机制建模、2024 风电场有功功率优化调度、2025 通用神经网络处理器下的核内调度问题。

| 信号 | 翻译要点 |
|---|---|
| 出现"信噪比""相噪""功率谱""阵列" | 需要噪声/干扰建模，必须单独验证噪声假设 |
| 出现"复杂度""存储量""吞吐""时延" | 优化目标含**资源代价**，要给复杂度分析而非只给结果 |
| 出现"架构""处理器""核内" | 存在硬件约束（片上存储、并行度），约束漏写=模型不可行 |
| 华为题标注 | 额外参评华为专项奖，策略上值得争取但不要为冲奖牺牲论文完整性 |

## B 题信号

**典型形态**：通信/光谱/材料/链路等"机理+数据"混合建模。历年样本：2020 汽油辛烷值建模、2021 空气质量预报二次建模、2022 方形件组批优化问题（华为题）、2023 DFT 类矩阵的整数分解逼近、2024 WLAN 组网中网络吞吐量建模、2025 无线通信系统链路速率建模。

| 信号 | 翻译要点 |
|---|---|
| "二次建模""改进模型" | 基线模型是**必做项**，必须复现并对比 |
| "逼近""分解""精度" | 存在精度–代价权衡，需给帕累托或权衡曲线 |
| "组批""整数" | 组合优化，必须给可行性证明与规模适应性 |
| 出现实测数据表 | 需要数据清洗章节（异常值、量纲统一、缺失） |

## C 题信号

**典型形态**：数据驱动、评价体系、医学与工程数据分析。历年样本：2020 面向康复工程的脑电信号分析和判别模型、2021 帕金森病的脑深部电刺激治疗建模研究、2022 汽车制造公司涂装-总装缓存区调序调度优化问题、2023 大规模创新类竞赛评审方案研究、2024 数据驱动下磁性元件的磁芯损耗建模、2025 围岩裂隙精准识别与三维模型重构。

| 信号 | 翻译要点 |
|---|---|
| "识别""分类""判别" | 混淆矩阵、指标取舍（精度 vs 召回）必须说明 |
| "评审方案""评价" | 指标体系 + 权重 + 一致性检验三件套 |
| "图像""裂隙""重构" | 图像预处理与几何量测精度是得分点 |
| 出现"生产调度""缓存区" | 排队/调度模型，约束表要逐条列举 |

## D 题信号

**典型形态**：材料/器件/地理/碳排/资源排布等系统级建模。历年样本：2020 无人机集群协同对抗、2021 抗胰腺癌候选药物的优化建模、2022 PISA 架构芯片资源排布问题（中兴题）、2023 区域双碳目标与路径规划研究、2024 大数据驱动的地理综合问题、2025 低空湍流监测及最优航路规划。

| 信号 | 翻译要点 |
|---|---|
| "路径规划""最优航路" | 需给路径可行性（避障、能耗）与对比基准 |
| "双碳""目标" | 指标体系与情景设定要明确，需情景对比 |
| "集群对抗""博弈" | 交战规则必须翻译成可计算的收益函数 |
| 中兴题标注 | 与华为题同类（企业命题），但**不参评华为专项奖** |

## E 题信号

**典型形态**：医学信号、定位、图像与故障诊断等强数据题。历年样本：2020 能见度估计与预测、2021 信号干扰下的超宽带(UWB)精确定位问题、2022 草原放牧策略研究、2023 出血性脑卒中临床智能诊疗建模、2024 高速公路应急车道启用建模、2025 高速列车轴承智能故障诊断问题。

| 信号 | 翻译要点 |
|---|---|
| "定位""精度""干扰" | 要误差模型与置信区间，不能只给单点估计 |
| "故障诊断""特征" | 特征提取过程要可解释，避免纯黑箱 |
| "估计/预测" | 明确预测对象、时域、评价指标 |
| "脑电""临床""诊疗" | 医学结论必须有临床/生物合理性讨论 |

## F 题信号

**典型形态**：气象、天文、交通、美学等跨界综合题。历年样本：2020 飞行器质心平衡供油策略优化、2021 航空公司机组优化排班问题、2022 COVID-19 疫情期间生活物资的科学管理问题、2023 强对流降水临近预报、2024 X 射线脉冲星光子到达时间建模、2025 江南古典园林的美学特征建模。

| 信号 | 翻译要点 |
|---|---|
| "美学特征""量化" | 主观概念必须先给可操作化定义，否则全题崩塌 |
| "临近预报""时空" | 时空建模，需说明泛化能力与不确定性 |
| "排班""物资管理" | 多目标权衡，权重来源要说明 |
| "质心平衡""供油" | 力学守恒关系是硬约束，必须显式写出 |

## 翻译完成判据

一份合格的翻译报告应能让**未读过原题的队友**回答以下问题：

1. 这题属于哪一族？主要考什么？
2. 一共几问？每一问要求交出什么具体形式的东西？
3. 数据在哪、多大、什么口径、有哪些坑？
4. 哪一问是关键问（拿分问）？哪一问最容易做偏？
5. 命题方是谁？是否华为题？
6. 还剩哪些地方题目没说清、需要自己做合理假设并声明？
