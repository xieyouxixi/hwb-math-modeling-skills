# AI 使用披露合规核对清单

## A. 真实性

| # | 检查项 | 通过标准 |
|---|---|---|
| A1 | 使用/未使用判断真实 | 与队员实际行为一致 |
| A2 | 无未发生记录的填写 | 每条清单项都能对应真实行为 |
| A3 | 无遗漏的已发生使用 | 特别是 C4—C6 类（数据处理、模型推导、文本生成） |
| A4 | 用途描述不缩水 | 未把"生成初稿"降级为"语言润色" |
| A5 | 用途描述不夸大 | 未把未使用的工具写进清单 |

## B. 边界（"辅助工具而非主导手段"）

| # | 检查项 | 通过标准 |
|---|---|---|
| B1 | 明确列出 AI 未参与的环节 | 至少覆盖：赛题理解、模型建立、核心推导、结果判断、结论形成 |
| B2 | 核心贡献归属清楚 | 论文核心贡献可追溯到队员的工作 |
| B3 | 无"以 AI 为主导"的表述 | 不出现"由 AI 给出模型"这类描述 |
| B4 | 若确有核心环节借助 AI | **如实标注**，并说明人工复核方式（不得隐瞒） |

## C. 一致性

| # | 检查项 | 通过标准 |
|---|---|---|
| C1 | 与论文版本一致 | 详情中提到的位置在定稿论文中确实存在 |
| C2 | 与代码一致 | 若声称使用了代码辅助，代码可运行且逻辑自洽 |
| C3 | 与引用一致 | 正文/参考文献中已按研赛要求注明 AI 产品来源 |
| C4 | 声明与详情一致 | 两份材料的环节、工具、程度描述不矛盾 |

## D. 匿名与安全

| # | 检查项 | 通过标准 |
|---|---|---|
| D1 | 无培养单位 | 材料中不出现学校/院所名称 |
| D2 | 无姓名 | 不出现队员或指导教师姓名 |
| D3 | 无队伍编号 | 不出现队伍编号 |
| D4 | 无账号信息 | 不出现工具账号、邮箱、API Key |
| D5 | 无赛题原文粘贴 | 详情中不含完整赛题原文 |
| D6 | 无第三方敏感材料 | 未包含未公开的内部材料 |

## E. 研赛规则符合性

| # | 检查项 | 依据 |
|---|---|---|
| E1 | 已按当年模板要求位置放置 | 官方《竞赛论文模板》 |
| E2 | 引用 AI 产出已注明来源 | 《竞赛通知》：引用程序（包括人工智能产品）须注明来源 |
| E3 | 未被用作规避查重的手段 | 《竞赛通知》：相似度检测 + 违规论文判定 |
| E4 | 未在竞赛期间将论文送第三方查重 | 《竞赛通知》：否则造成论文泄露后果自负 |

## F. 输出格式

```markdown
## 核对结论
（2—4 句：整体合规性 + 最高风险）

## 问题清单
| 等级 | 位置 | 类型（真实/边界/一致/匿名/规则） | 说明 | 风险 | 修改建议 |

## 逐项核对结果
（A—E 各表，填"通过 / 不通过 + 证据"）

## 修改优先级
1. …
2. …
3. …

## 待核对事项
- …
```

等级判定：

| 等级 | 判据 |
|---|---|
| 严重问题 | D1—D4 不通过（匿名违规 → 论文无效）；A1—A4 不通过（虚假披露 → 学术诚信风险）；E3 不通过 |
| 重要问题 | B1/B2 不通过；C1/C3/C4 不通过；E2 不通过 |
| 一般问题 | C2、E1、E4 不通过 |
| 优化建议 | 措辞与结构层面的提升项 |

## 附：研赛 AI 相关规则原文要点

1. 参赛队**可使用人工智能产品，仅作为答题的辅助工具，而非主导手段**，不能代替参赛队伍的独立思考和竞赛答题的主体工作。
2. 正文、数字模型、公式引用等**所有引用文献、引用程序（包括人工智能产品）均按规定注明来源**。
3. 专家委员会对**所有论文**进行查重处理，重复率高于阈值的论文，一般直接判定为"违规论文"。
4. **引用他人程序也须明确标注引用来源**，否则发现程序雷同，按抄袭认定为"违规论文"。
5. 各参赛队**不得在竞赛期间将参赛论文送第三方查重**，否则造成论文泄露后果自负。
6. 违纪核实后：取消参赛或获奖资格，**强制停赛一年**，并通报参赛单位。

> 以上为历届《竞赛通知》稳定口径。当届如有更新，以当届《竞赛通知》为准。
