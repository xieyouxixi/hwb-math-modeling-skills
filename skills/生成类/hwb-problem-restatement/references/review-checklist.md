# 问题重述自查清单

按顺序逐项核对。每项给出结论（通过/不通过）与证据位置。

## A. 题意保持

| # | 检查项 | 通过标准 |
|---|---|---|
| A1 | 问题数量一致 | 重述的问题数 = 原题问题数（研赛常 3—5 问） |
| A2 | 任务无遗漏 | 原题每个"请……"动词都在重述中有对应表述 |
| A3 | 附属要求无遗漏 | "并说明理由""并给出指标""并讨论"等全部保留 |
| A4 | 数字与单位准确 | 样本量、时间范围、精度、阈值与原题一致 |
| A5 | 约束无失真 | 硬约束未被弱化（"必须"没被写成"尽量"） |
| A6 | 附件作用已说明 | 每份被使用的附件都在重述中点名 |
| A7 | 补充说明已生效 | 若存在补充/更正说明，重述采用最新口径 |
| A8 | 术语一致 | 未自造近义词替代题目术语 |
| A9 | 无新增事实 | 没有题目里不存在的数据、假设或要求 |
| A10 | 无删减压力 | 未为压缩篇幅而删掉实质任务 |

## B. 章节边界

| # | 检查项 | 不通过的表现 |
|---|---|---|
| B1 | 无模型名 | 出现具体模型/算法名称 |
| B2 | 无数据预处理 | 出现插值、去噪、归一化等处理描述 |
| B3 | 无公式推导 | 出现目标函数、约束式、方程 |
| B4 | 无结果 | 出现任何数值结果或精度 |
| B5 | 无创新点 | 出现"本文创新" |
| B6 | 无结论 | 出现"因此方案为……" |

## C. 研究综述

| # | 检查项 | 通过标准 |
|---|---|---|
| C1 | 相关性 | 综述内容与本题任务直接相关 |
| C2 | 均衡性 | 覆盖主要方法族，不偏重单一方向 |
| C3 | 证据真实 | 无虚构作者/期刊/年份/结论 |
| C4 | 有局限分析 | 说明了现有方法的限制 |
| C5 | 有切入点 | 结尾 1—2 句交代本文切入角度（不剧透结果） |
| C6 | 篇幅合适 | 400—600 字 |

## D. 研赛合规

| # | 检查项 | 通过标准 |
|---|---|---|
| D1 | 匿名 | 无培养单位、姓名、队伍编号 |
| D2 | 模板 | 章节标题层级符合当年官方模板 |
| D3 | 篇幅 | 重述 ≤2 页 |
| D4 | 格式 | 无残留的"待补充""此处略"占位 |
| D5 | 图表 | 若非必需，重述不插图（问题分析段落更适合作图） |

## E. 语言

| # | 检查项 |
|---|---|
| E1 | 第三人称，无口语化表达 |
| E2 | 长句已拆分，单句不超过 60 字为宜 |
| E3 | 无同义词硬替换导致的语病（如"构建"与"建立"混用不当） |
| E4 | 段落长度均衡，无单句成段 |
| E5 | 中英文标点统一，数字与单位间空格一致 |

## 输出格式

```markdown
## 审查结论
（2—4 句）

## 问题清单
| 等级 | 位置/原文 | 类型 | 说明 | 评阅影响 | 修改建议 |

## 逐项核对
（A/B/C/D/E 各表，填"通过 / 不通过 + 证据"）

## 修改优先级
1. …
2. …
3. …

## 待核对事项
- …
```

等级判定：

| 等级 | 判据 |
|---|---|
| 严重问题 | 违反 D1（匿名）或 B 类任一项，或 A1/A2/A5/A9 不通过 |
| 重要问题 | A3/A4/A6/A7/A8 或 C1/C3/C4 不通过 |
| 一般问题 | B/C 其他项、E1/E2/E4 不通过 |
| 优化建议 | 语言与结构层面的可提升项 |
