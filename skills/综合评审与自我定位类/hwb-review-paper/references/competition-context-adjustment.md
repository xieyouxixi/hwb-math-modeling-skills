# CPGMCM Competition Context Adjustment（三维竞争校准）

本规则只用于"华为杯"中国研究生数学建模竞赛（CPGMCM，研究生赛）的奖项竞争力预测。它不修改论文质量原始判断，不代表官方名额分配或确定获奖结果。

研究生赛**不设赛区、不设本科组/高职高专组、也无"省奖/国奖"双层模型**。竞争校准维度改为三维：

1. **赛题（A—F）难度与选题拥挤度**；
2. **参赛单位（研究生培养单位）历史获奖记录**——组委会规定每个培养单位每届一等奖不超过 3 项，单位规模与历史表现影响实际竞争力；
3. **是否选择华为赛题**——选华为赛题可另评**华为专项奖**（一等奖 4 队、二等奖 12 队，奖金与常规奖累加）。

## 1. 必须输入

对 CPGMCM 数值评审，除完整赛题和论文外，应取得：

- 赛题编号：`A`—`F` 之一；
- 参赛单位全称（可选；留空时单位修正标记为 `无法计算/待补充`）；
- 是否选择华为赛题：`是` 或 `否`。

缺少赛题编号时，只完成论文质量评分，不进行任何竞争修正。缺少参赛单位或华为赛题选择时，对应修正标记为 `待补充`，不得猜测单位历史或华为赛题归属。

## 2. 数据文件

- `data/problem_difficulty_scores.csv`：A—F 六题的**经验**难度得分、选题拥挤度与选题建议（非官方，仅作审阅提示）。
- `data/unit_awards_template.csv`：参赛单位获奖记录**空白模板**，须由使用者从官方获奖名单自行填写；本仓库不提供任何单位获奖数据。
- `data/cpgmcm_annual_statistics.csv`：历年参赛单位数、参赛队数与获奖总量（仅含已公开可核实数据）。

只根据数据文件的实际字段判断。单位匹配应先使用去除首尾空格后的精确名称，再使用统一全半角括号与空白的规范化名称；模糊匹配只能作为候选提示，未经用户确认不得应用单位修正。

## 3. 三轨分数

始终保留：

1. `论文质量原始得分`：评分细则逐项所得分数；
2. `格式质量系数`；
3. `论文质量最终得分 = 原始得分 × 格式质量系数`；
4. `赛题竞争修正分`；
5. `华为赛题竞争修正分`（仅当选华为赛题时有意义）。

赛题、单位与华为赛题不得回写或伪装成论文质量扣分。所有修正必须逐项展示依据、增减值、封顶和不确定性。

## 4. 赛题难度修正

从 `problem_difficulty_scores.csv` 读取该题 `difficulty_score`（0—100）。`difficulty_score` 越高，表示技术门槛越高、同质量论文相对更易突出（选题拥挤度越低），给予正向修正：

`赛题难度修正值 = clamp((D - 50) / 50 × 15, -15, +15)`

- D > 50：正向，最高 `+15`；
- D < 50：负向，最低 `-15`；
- D = 50：无修正。

修正只作用于 `赛题竞争修正分`，不改变论文质量最终得分。该方向为经验启发式，非官方口径，须明确标注。

## 5. 参赛单位修正

### 单位在已填模板中

- 输出该单位各届一等奖、二等奖、三等奖队数；
- 历史获奖越强，单位内竞争越激烈（受每单位最多 3 项一等奖上限约束），给予温和负向先验：

`单位修正值 = clamp(-(一等奖 + 二等奖 + 三等奖) / 60 × 5, -5, 0)`

- 该修正反映单位内历史竞争环境，不是论文质量加减分。

### 单位未提供或不在模板中

- 明确输出：`该单位未提供历史获奖数据，单位修正无法计算。`
- 单位修正为 `0`，置信度降为 `低`；
- 不得把"未提供数据"解释为该单位没有竞争力或学生无法获奖。

## 6. 华为赛题修正

仅当 `是否选择华为赛题 = 是` 且论文质量最终得分达到一定门槛时应用（开启额外奖项通道——华为专项奖）：

- `最终得分 ≥ 55`：`华为赛题修正值 = +8`；
- `45 ≤ 最终得分 < 55`：`华为赛题修正值 = +4`；
- `最终得分 < 45`：修正为 `0`。

`华为赛题竞争修正分 = clamp(最终得分 + 华为赛题修正值, 0, 90)`。

不选择华为赛题时，华为赛题修正标记为 `不适用`，不输出对应竞争分。

## 7. 计算顺序

令 `S` 为论文质量最终得分：

1. `赛题竞争修正分 = clamp(S + 赛题难度修正 + 单位修正, 0, 90)`；
2. 若选华为赛题：`华为赛题竞争修正分 = clamp(S + 华为赛题修正值, 0, 90)`；
3. 论文质量分、赛题竞争修正分、华为赛题竞争修正分必须同时输出，不得只显示一个分数。

优先运行 `scripts/competition_context.py`，避免手算错误。

## 8. 置信度

- 完整赛题、完整论文、赛题编号、华为赛题选择齐全，且单位已填并精确匹配：默认 `中等`；
- 单位缺失、单位需人工确认、华为赛题归属不明：`低`；
- 不得因数据字段齐全而声称高置信度，因为赛题难度、单位历史与华为专项奖均为经验先验。

## 9. 必须提示的创新盲区

每份 CPGMCM 报告必须说明：每年存在少量论文因解题路径非常新颖、超出常见评审框架而获得高奖。AI 评审主要依据可识别的任务完成度、数学正确性、验证证据和历史评阅规律，可能低估评委未曾预期的真正创新路径；目前无法可靠消除该盲区。

## 10. 时间与更新

所有赛题难度、单位历史与华为专项奖规则均为历史/经验数据。报告必须列出数据适用年份，并提醒下一年度参赛规模、选题方向、单位训练体系与华为赛题设置可能变化；一切以当届官方文件为准。
