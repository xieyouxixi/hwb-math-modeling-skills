# 模型适配性评估方法

## 一、五问判定法

对每个候选模型依次回答五个问题。**任一问答不上来，就不能推荐该模型。**

| 问 | 内容 | 不合格表现 |
|---|---|---|
| ① 任务匹配吗？ | 模型输出 = 题目要求？ | 题目要方案，模型只给预测值 |
| ② 数据够吗？ | 样本量/维度/标注满足最低要求？ | 样本 80 个却用深度网络 |
| ③ 假设成立吗？ | 核心假设在本题成立？ | 假设独立同分布，数据是时序 |
| ④ 能验证吗？ | 有独立验证路径？ | 只能用训练误差自证 |
| ⑤ 四天做得完吗？ | 含调参与验证的总工作量？ | 需要数天训练 |

## 二、数据充分性参考阈值

| 模型族 | 经验最低数据要求 | 数据不足时的降级方案 |
|---|---|---|
| 多元线性/岭回归 | 样本 ≥ 10×特征数 | 主成分回归、变量筛选 |
| 逻辑回归 | 每类事件 ≥ 10 例（EPV 规则） | 正则化、降维 |
| 树模型（RF/XGBoost） | 样本 ≥ 数百，特征 ≤ 数百 | 减少特征、限制深度 |
| 神经网络 | 样本 ≥ 数千（或强数据增强） | 改用树模型或线性模型 |
| SVM | 样本 ≥ 数十×类数 | 线性核 + 特征工程 |
| 时间序列（ARIMA/指数平滑） | 序列长度 ≥ 50 期 | 简单移动平均、灰色预测 |
| 深度时序（LSTM/Transformer） | 序列 ≥ 数千步 | 轻量模型 + 物理特征 |
| 卡尔曼滤波 | 状态维度可控、噪声可估 | 简化状态、鲁棒滤波 |
| 聚类 | 样本 ≥ 数十×维度 | 降维后聚类 |
| 层次分析/熵权法 | 指标数 ≤ 9（AHP 一致性） | 分组 AHP 或客观赋权 |
| 遗传算法/模拟退火 | 目标函数可快速求值 | 代理模型 + 局部搜索 |
| 整数规划 | 变量数在求解器能力内 | 列生成、拉格朗日松弛、启发式 |

> 阈值是经验参考，不是硬规则。若低于阈值，**必须**在论文中说明并给出风险讨论，而不是装作没看见。

## 三、假设成立性的检查表

| 模型族 | 必须先确认的假设 |
|---|---|
| 线性回归族 | 线性关系、误差独立同分布、无严重共线、无异方差 |
| 广义线性模型 | 分布假设正确、连接函数合适、离散度合理 |
| 树模型 | 特征可比较（类别变量需编码）、样本代表性 |
| 神经网络 | 数据量、分布一致性、可解释性要求 |
| 时间序列 | 平稳性、自相关结构、无结构性突变 |
| 卡尔曼滤波 | 线性动态、高斯噪声、噪声统计已知 |
| 排队论 | 到达过程、服务时间分布、稳态条件 |
| 微分方程模型 | 连续介质/平均场近似、参数可辨识 |
| 图论/网络流 | 网络结构稳定、容量已知 |
| 统计评价方法 | 指标独立或相关性可控、专家判断可靠性 |
| 博弈模型 | 理性假设、收益函数可定义、信息结构明确 |
| 元启发式 | 解空间可编码、目标函数可快速求值 |

## 四、失效条件必须具体

| 不合格写法 | 合格写法 |
|---|---|
| 数据质量差时会失效 | 当特征间相关系数 > 0.9 时，最小二乘系数方差急剧放大，可能出现符号反转 |
| 精度可能不足 | 本题训练样本仅 120 例而特征 40 维，逻辑回归的 EPV = 3，远低于 10，系数估计不稳定 |
| 假设不总成立 | 题目数据为同一设备连续采集，样本不独立，交叉验证会低估泛化误差 |

## 五、验证路线必须独立

对每个模型指定至少一种：

| 验证方式 | 适用 |
|---|---|
| 留出集 / K 折交叉验证 | 数据驱动模型 |
| 时间外推验证 | 时序模型 |
| 留一工况 / 分层验证 | 存在分组结构的医学、工程数据 |
| 与物理守恒或边界条件对照 | 机理模型 |
| 与解析解/特例对照 | 数值方法 |
| 与基线算法对比（含 gap） | 优化模型 |
| 多随机种子稳定性 | 含随机性的模型 |
| 权重扰动一致性检验 | 评价类模型 |

## 六、替代方案的给出方式

替代方案必须包含**代价**，否则等于没给：

```text
原方案：随机森林回归（适配度高，但可解释性弱，题目要求解释影响因素）
替代 A：岭回归 + 交互项（可解释，但需手工构造交互特征，预测精度可能下降）
替代 B：梯度提升树 + SHAP 解释（兼顾精度与解释，但计算量增加，四天内约需 0.5 人天）
推荐：替代 B
```

## 七、输出档案格式

```markdown
## 模型档案：<模型名>

| 项 | 内容 |
|---|---|
| 用途（本题） | 用于第 N 问的 <具体任务> |
| 类别 | 回归 / 分类 / 优化 / 评价 / 机理 / 时序 |
| 数据要求 | 样本量、特征类型、标注要求 |
| 最低数据满足情况 | 本题数据：<数量>；结论：满足 / 勉强 / 不满足 |
| 核心假设 | 逐条列出 |
| 假设成立情况 | 逐条判定 + 证据 |
| 优点 | 本题语境下的优点（非通用优点） |
| 局限 | 本题语境下的局限 |
| 失效条件 | 具体条件 + 后果 |
| 验证方式 | 独立验证路线 |
| 实现成本 | 人天估计 + 最小实现路径 |
| 适配结论 | 推荐 / 有条件推荐 / 不推荐 |
| 替代方案 | 含代价 |
```

## 八、边界说明

- 本 Skill 给的是**适配性判断**，不是“这个模型好不好“的学术评价。
- 不得声称“该模型在本题中一定优于其他模型“——只能说在给定数据与用途下更适配。
- 若用户提供的数据信息不足，必须列出需要补充的信息，而不是给出模糊结论。
