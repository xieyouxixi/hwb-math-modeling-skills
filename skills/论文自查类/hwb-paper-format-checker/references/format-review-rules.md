# 研赛论文格式审查规则

## 一、审查基准

研赛论文格式的基准是**当年官方《竞赛论文模板》与《论文格式规范》**，而不是通用学术论文规范。因此在任何一处冲突时，**以官方模板为准**。

> 历届《竞赛通知》明确：论文必须按当年附件《竞赛论文模板》编写，并确保提交的论文首页为封皮（**不可删除，包含团队相关信息，4 个图标不能替换**），第二页起为摘要页和正文页。**除首页外其他页面中不允许出现单位、参赛人员姓名、队伍编号等信息，否则视为违规，论文无效。**

## 二、一票否决项（置顶检查）

| 编号 | 检查项 | 判定 | 违反后果 |
|---|---|---|---|
| X1 | 除首页外出现培养单位名称 | 字面检索校名/院所名 | **论文无效** |
| X2 | 除首页外出现参赛人员姓名 | 检索常见姓名列 | **论文无效** |
| X3 | 除首页外出现队伍编号 | 检索队伍编号字样 | **论文无效** |
| X4 | 首页封皮被删除或替换为自定义封面 | 首页应为官方模板封皮 | 格式违规 |
| X5 | 首页 4 个图标被替换/删除/改动 | 逐图标比对 | 格式违规 |
| X6 | 摘要超过两页 | 按模板页边界核对 | 违反格式规范 |
| X7 | 未使用统一摘要页 | 比对摘要页模板 | 违反格式规范 |
| X8 | PDF 命名不符合 `试题编号+队伍编号` | 字面核对（如 `A24000010001.pdf`） | 提交对应失败 |
| X9 | 提交的不是 PDF 或对 PDF 做了压缩 | 核对格式与体积 | 不符合要求 |

## 三、页面结构与篇幅

| 检查项 | 要求 |
|---|---|
| 页面顺序 | 封皮 → 摘要页 → 正文 → 参考文献 → 附录（若模板另有规定以模板为准） |
| 页码 | 连续；从摘要页或正文起编（按模板） |
| 目录 | 若模板含目录，须与正文一致；若模板不含，不要自行添加 |
| 正文页数 | 不超过当年模板规定的上限 |
| 各章比例 | 建议：重述 + 问题分析 ≤ 20%；模型建立与求解 ≥ 50%；检验与灵敏度 ≥ 10% |
| 空白页 | 无异常空白页 |

## 四、标题与层级

| 检查项 | 要求 |
|---|---|
| 层级数 | 不超过 3 级（章 / 节 / 小节） |
| 编号 | 连续、无跳号（如 3.1 后直接 3.3） |
| 用语 | 标题为名词短语，不用完整句 |
| 一致性 | 同一层级的标题风格统一（不混用疑问句与陈述句） |
| 位置 | 不与正文混排，不出现孤行标题（标题在页底、内容在下页） |

## 五、图表

| 检查项 | 要求 |
|---|---|
| 编号连续 | 图 1、图 2……表 1、表 2……不跳号 |
| 正文引用 | 每图每表至少被正文引用一次（「如图 3 所示」） |
| 位置 | 图随文，不出现图在引用之前很远的位置 |
| 图注 | 置于图下方；表注置于表上方 |
| 单位 | 坐标轴、表头均带单位 |
| 分辨率 | 位图足够清晰（一般 ≥ 300 dpi 或矢量图） |
| 中英文 | 图中文字与正文语言一致 |
| 三线表 | 表格建议使用规范三线表 |
| 可读性 | 字号不小于正文的 80%；颜色在黑白打印下仍可区分 |

## 六、公式

| 检查项 | 要求 |
|---|---|
| 编号 | 连续；仅对正文引用的公式编号 |
| 引用 | 关键公式在正文中被引用 |
| 排版 | 变量斜体、函数名与单位正体、矩阵粗体 |
| 换行 | 长公式换行在运算符后，对齐等号 |
| 单位 | 量纲自洽；带单位的结果给出单位 |

## 七、文件卫生

| 检查项 | 处理 |
|---|---|
| Word 临时文件 | 删除 `~$*.docx` |
| 批注与修订 | 全部接受/拒绝后清除 |
| **文档属性** | **清空作者、公司、管理者、最后修改者字段**（最常见身份泄露点） |
| PDF 元数据 | 检查 Title/Author/Producer 是否有个人信息 |
| 隐藏文字 | 关闭隐藏文字显示后确认无残留 |
| 重复版本 | 只保留一份主版本 |
| 图片嵌入 | 无丢失链接 |

## 八、语言与标点

| 检查项 | 要求 |
|---|---|
| 标点 | 中文段落用全角标点，英文/公式内用半角 |
| 数字与单位 | 如 `10 m/s`（数字与单位间空格，按模板要求） |
| 缩写 | 首次出现给全称 |
| 错别字 | 通读一遍；重点检查术语（如「噪声」/「噪音」统一） |
| 一致 | 同一概念全篇用同一词 |

## 九、扣分标定

| 项 | 扣分幅度（格式规范分，满分 100） |
|---|---|
| X1—X3（匿名） | **直接判不合格，不进入分数计算** |
| X4—X7（模板与摘要页） | 每项 −15 ~ −25 |
| X8—X9（命名与格式） | 每项 −10 |
| 页面结构缺失 | 每项 −5 |
| 篇幅严重失衡 | −5 ~ −10 |
| 标题跳号/层级混乱 | 每处 −2 |
| 图表未引用/未编号 | 每处 −3 |
| 公式未编号/未引用 | 每处 −2 |
| 参考文献体例不统一 | −5 |
| 文档属性残留身份信息 | −10（并提示一票否决风险） |
| 标点/间距不统一 | −2 |
| 错别字 | 每处 −1（上限 −5） |

## 十、格式质量系数的映射

`hwb-review-paper` 会接入本 Skill 的格式规范分，按下列方式折算为格式质量系数：

```text
格式质量系数 = (格式规范分映射到 [-10, 10] + 10) / 20
```

即格式规范分 100 → 系数 1.0；格式规范分 50 → 系数 0.75；格式规范分 0 → 系数 0.5。

**注意**：格式质量系数用于修正论文质量分，**不得**用它掩盖内容层面的问题。匿名违规属于**资格问题**，不是分数问题。
