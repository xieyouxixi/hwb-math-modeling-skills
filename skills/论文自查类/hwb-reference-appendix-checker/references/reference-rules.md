# 参考文献与引用规则

## 一、研赛的引用硬要求

《竞赛通知》明确：

> 参赛队员必须遵守科学道德与学术规范，**引用文献必须注明来源**。……**引用他人程序也需明确标注引用来源**，否则发现程序雷同，按抄袭认定为"违规论文"。

并且（第二十一届起）：

> 正文、数字模型、公式引用等**所有引用文献、引用程序（包括人工智能产品）均按规定注明来源**。

因此引用问题在研赛**不是格式问题，而是资格问题**。

## 二、引用一致性的三种错误

| 错误 | 表现 | 风险 |
|---|---|---|
| 引而未列 | 正文有 [7]，文献表只有 6 条 | 严重 |
| 列而未引 | 文献表有 15 条，正文只用到 9 条 | 一般（视为凑数） |
| 编号错位 | [5] 在正文指的是 A，文献表里是 B | 严重 |

核对方法：抽取正文全部 `[n]`，与文献表编号做集合运算。

## 三、文献条目格式要求

**统一性优先于具体格式**。无论采用 GB/T 7714 数字式还是其他体例，全表必须一致：

| 类型 | 必备要素 |
|---|---|
| 期刊论文 | 作者. 题名[J]. 刊名, 年, 卷(期): 起止页. |
| 会议论文 | 作者. 题名[C]//会议名. 出版地: 出版者, 年: 页. |
| 学位论文 | 作者. 题名[D]. 城市: 学校, 年. |
| 专著 | 作者. 书名[M]. 版本. 出版地: 出版者, 年: 页. |
| 标准 | 标准号 标准名[S]. 出版地: 出版者, 年. |
| 电子资源 | 作者. 题名[EB/OL]. (发布日期)[引用日期]. URL. |
| 程序/软件 | 名称[CP/OL] 或 [Z]. 版本. 来源. |

### 常见不规范

- 中英文文献混排但体例不同（中文用 GB/T，英文用 APA）；
- 作者姓名格式不统一（中文全名 vs 英文缩写姓氏前置）；
- 缺卷期页；
- 期刊名简写不一致；
- 网址无引用日期。

## 四、引用充分性

| 检查项 | 要求 |
|---|---|
| 关键方法有出处 | 使用他人提出的模型/算法时须引用 |
| 数据来源有说明 | 题目外部数据须注明来源 |
| 公式引用有标注 | 直接引用的公式须标来源 |
| 常识性内容不必引用 | 避免为凑数滥引 |
| 避免"综述式堆引" | 在方法处引 1—2 篇最相关即可 |

## 五、AI 与程序引用（研赛重点）

| 情形 | 要求 |
|---|---|
| 代码使用了开源库 | 在参考文献或代码注释中注明库名与版本 |
| 算法来自论文 | 在模型建立处引用该论文 |
| 使用了 AI 辅助生成代码或文字 | 按研赛要求**注明来源**，并在 AI 使用披露材料中登记 |
| 直接使用他人程序 | 必须明确标注引用来源，否则按抄袭认定 |

## 六、匿名性检查（易被忽略）

参考文献与附录**属于"除首页外"的页面**，因此：

- 不得出现培养单位名称（如"浙江大学数学科学学院"这类单位署名）；
- 不得出现指导教师的致谢；
- 不得出现作者姓名与队伍编号；
- 若引用本队前期成果，须匿名化处理。

发现任一情况 → **一票否决级严重问题**。

## 七、输出要求

对每个问题给出：位置（章节 + 文献编号）、错误类型、证据（正文与文献表原文对照）、修改建议（补列/删除/改写）。
