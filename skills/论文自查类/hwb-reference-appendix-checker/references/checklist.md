# 参考文献与附录检查清单

## A. 引用一致性

| # | 检查项 | 通过标准 |
|---|---|---|
| A1 | 正文引用编号与文献表一一对应 | 集合相减为空 |
| A2 | 无「引而未列」 | 每个 `[n]` 都能找到条目 |
| A3 | 无「列而未引」 | 每条文献都被引用（或标注为"阅读材料"并说明） |
| A4 | 编号顺序与出现顺序一致 | 首次引用顺序递增 |
| A5 | 多处引用格式一致 | 统一用 `[1,2]` 或 `[1-3]` |

## B. 文献条目规范

| # | 检查项 |
|---|---|
| B1 | 全表体例统一（同一套 GB/T 7714 或同一套英文体例） |
| B2 | 作者姓名格式统一 |
| B3 | 期刊/会议/学位论文类型标识齐全（[J]/[C]/[D]/[M]/[S]/[EB/OL]） |
| B4 | 卷、期、页码齐全（可得时） |
| B5 | 网址附引用日期 |
| B6 | 中英文文献不混用两套体例 |
| B7 | 无编造的文献条目（**逐条核对可查性**） |

## C. 引用充分性

| # | 检查项 |
|---|---|
| C1 | 使用他人模型/算法处有引用 |
| C2 | 外部数据来源有说明 |
| C3 | 引用的公式标明出处 |
| C4 | 无「无来源直接使用他人方法」 |
| C5 | 无滥引凑数（引用量与使用量匹配） |

## D. AI 与程序引用

| # | 检查项 | 依据 |
|---|---|---|
| D1 | 引用的程序已注明来源 | 《竞赛通知》硬要求 |
| D2 | 引用的 AI 产品已注明来源 | 第二十一届起明确 |
| D3 | 使用的开源库已在参考文献或代码注释中说明 | 规范 |
| D4 | 与 `hwb-ai-usage-disclosure` 披露材料一致 | 一致性 |

## E. 附录

| # | 检查项 |
|---|---|
| E1 | 正文提到的附录标号在附录中确实存在 |
| E2 | 附录无空壳（不只有「见附件」） |
| E3 | 附录不与正文大段重复 |
| E4 | 公式推导完整可读 |
| E5 | 数据预处理细节可复述 |

## F. 代码与支撑材料

| # | 检查项 | 通过标准 |
|---|---|---|
| F1 | 附件 ≤50MB | 数值核对 |
| F2 | 命名 = `试题编号+队伍编号` | 字面核对 |
| F3 | 论文中已注明上传了附件 | 正文中有说明 |
| F4 | 代码有入口与依赖说明 | 可运行 |
| F5 | 无硬编码个人路径 | 无 `C:\Users\<姓名>` |
| F6 | 随机种子固定或说明 | 可复现 |
| F7 | 按说明能跑出主要结果 | 抽验 |

## G. 匿名与文件卫生

| # | 检查项 | 通过标准 |
|---|---|---|
| G1 | 文献/附录无培养单位 | 无校名/院所名 |
| G2 | 无姓名与致谢对象 | 无 |
| G3 | 无队伍编号 | 无 |
| G4 | 代码注释无身份信息 | 无 |
| G5 | 文档属性已清空作者/单位 | 检查 PDF/Word 属性 |
| G6 | 无 Word 临时文件与批注 | 已清理 |
| G7 | 无重复版本文件 | 只留一份主版本 |

## 输出格式

```markdown
## 审查结论
（2—4 句）

## 问题清单
| 等级 | 位置 | 类型 | 说明 | 评阅影响 | 修改建议 |

## 逐项核对
（A—G 各表）

## 修改优先级
1. …
2. …
3. …

## 待核对事项
- …
```

等级判定：

| 等级 | 判据 |
|---|---|
| 严重问题（P0） | G1—G3 不通过（身份泄露 → **论文无效**）；F1/F2 不通过（提交失败） |
| 严重问题（P1） | D1/D2 不通过（抄袭认定风险）；F7 不通过（复现失败） |
| 重要问题（P2） | A1—A4、E1—E3、F4、G5 不通过 |
| 一般问题（P3） | B1—B6、C1—C5、F5/F6、G6/G7 不通过 |
| 优化建议 | 排版、注释质量等 |
