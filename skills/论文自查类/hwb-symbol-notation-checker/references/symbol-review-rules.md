# 符号审查规则

## 一、符号表的六项完备性要求

| # | 要求 | 说明 |
|---|---|---|
| 1 | 全覆盖 | 正文（含公式、图表坐标轴、算法伪代码）中出现的每个符号都在表中有定义 |
| 2 | 无冗余 | 表中每个符号至少在正文出现一次 |
| 3 | 无冲突 | 一个符号只表示一个量；一个量只用一套符号 |
| 4 | 带单位 | 物理量型符号标注单位；无量纲量标注"无量纲" |
| 5 | 有说明 | 说明列写清含义，不只写"系数""参数" |
| 6 | 分组 | 按类别分组：常数 / 变量 / 参数 / 集合与指标 / 算子与函数 |

## 二、八类常见符号问题

### 2.1 未定义使用

正文出现符号但表中没有。**最常见**，尤其在附录代码与图注中。

### 2.2 定义了但未使用

表中列出但正文从未出现。通常是从其他题目论文里搬来的符号表，属于明显的"模板残留"。

### 2.3 一符多义

例如 `$n$` 在 2.1 节表示样本量，在 3.2 节表示迭代次数。**最严重**，会让公式无法阅读。

### 2.4 一义多符

同一个量在不同章节用了不同字母（如 $x_t$ 与 $X_t$、$	heta$ 与 $\Theta$）。会让评委怀疑是否在拼凑不同来源的内容。

### 2.5 单位缺失或量纲不自洽

典型：目标函数的各项量纲不一致却直接相加；物理量未标单位导致读者无法验证数量级。

### 2.6 上下标混乱

- 同一含义下标大小写不一致（$x_{i}$ 与 $x_{I}$）；
- 下标含义未说明（$a_{1}$、$a_{2}$ 分别代表什么）；
- 向量用下标表示分量时未说明约定。

### 2.7 数学排版不规范

| 类型 | 规范 |
|---|---|
| 变量、参数 | 斜体（$x$, $lpha$） |
| 函数名、算子 | 正体（$\sin$, $\log$, $\mathrm{tr}$） |
| 单位 | 正体（$\mathrm{m/s}$） |
| 矩阵、向量 | 粗体或带箭头，需在符号表说明约定 |
| 常数（自然对数底、虚数单位） | 正体 |
| 集合 | 大写花体或普通体，需说明 |

### 2.8 擅自改写题目符号

题目给定符号（如"记 $P$ 为功率"）被改成其他字母。会造成阅卷障碍，也容易被读成没认真读题。

## 三、审查流程

1. **抽取**：把符号表整理为三元组（符号, 含义, 单位）。
2. **全文扫描**：逐章抽取正文符号出现记录（含公式、图注、表头、伪代码）。
3. **做差集**：
   - 正文 − 表 = **未定义集**；
   - 表 − 正文 = **冗余集**。
4. **冲突检测**：对同一符号收集所有含义；对同一含义收集所有符号。
5. **量纲检查**：对出现在等式两侧的符号做量纲一致性检查。
6. **首次定义检查**：每个符号的首次出现位置是否伴随定义或指向符号表。

## 四、研赛语境的优先级

| 优先级 | 问题 | 理由 |
|---|---|---|
| P0 | 一符多义、一义多符 | 直接导致模型不可读 |
| P0 | 未定义使用 | 评委在核心章节遇阻 |
| P1 | 量纲不自洽 | 直接指向模型错误 |
| P1 | 擅自改写题目符号 | 被视为未读懂题目 |
| P2 | 冗余符号 | 模板残留，影响严谨印象 |
| P2 | 上下标不一致 | 阅读体验问题 |
| P3 | 排版斜正体 | 细节规范性 |

## 五、整改建议模板

对每类问题给出可直接执行的动作：

| 问题 | 整改动作 |
|---|---|
| 一符多义 | 为其中一个含义分配新符号（选相近但可区分的，如 $n$ → $n_{	ext{iter}}$），并全文替换 |
| 一义多符 | 选定一个为主，全文统一；在符号表加备注"A 处曾用 B 表示，已统一" |
| 未定义 | 补入符号表，并按类别归位 |
| 冗余 | 删除；若担心读者需要，移入"常用记号"附注 |
| 单位缺失 | 补单位；无量纲量写"无量纲" |
| 量纲不自洽 | 在模型建立章节补充无量纲化步骤或说明系数单位 |

## 六、边界说明

符号表的**完备性**是客观可核验的（做集合运算即可），但**分组与排序的美观度**属优化建议范畴。输出时不要把美观问题报成严重问题，以免稀释真正需要修的 P0 项。
