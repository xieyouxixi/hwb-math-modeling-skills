# 检验与灵敏度分析检查规则

研赛与本科赛事最明显的差别之一：**研赛对验证的要求实质性地更高**。三天赛程里常常来不及，四天赛程里没有验证就说不过去了。本文件给出判定标准。

## 一、什么算"独立验证"

| 算独立验证 | 不算独立验证 |
|---|---|
| 留出集 / 交叉验证（划分方式说明清楚） | 用训练集误差当验证结果 |
| 与基线模型对比（基线需复现） | 只与"理论上应更好"比较 |
| 物理/业务合理性检验（守恒、边界、单调性） | 只做统计指标 |
| 与解析解或已知特例对比 | 只看自己的结果"看起来合理" |
| 多随机种子/多情景的稳定性 | 单次运行报一个漂亮数 |
| 与实测数据对照（若题目提供） | 与文献数值勉强对比 |

**判定规则**：论文若只有一种验证方式，且方式是"训练误差"或"看起来合理"，判定为**未做独立验证**，按重要问题报出。

## 二、误差分析的检查要点

| 检查项 | 要求 |
|---|---|
| 误差分类 | 数据误差（测量/采样）、模型误差（假设不符）、数值误差（离散化/迭代）分开讨论 |
| 量级估计 | 各类误差给出量级，说明哪一类占主导 |
| 传播分析 | 说明输入误差如何影响输出（若题目要求高精度） |
| 与结论的关系 | 明确指出误差是否足以推翻结论 |

只写"由于数据存在噪声，误差不可避免"属于**无效误差分析**。

## 三、灵敏度分析的检查要点

| 检查项 | 要求 |
|---|---|
| 扰动对象 | 至少覆盖最关键的 2—3 个参数（而非任意选） |
| 扰动范围 | 给出范围依据（±10%？物理可达范围？） |
| 输出指标 | 明确观察哪个输出量的变化 |
| 结论 | **给出稳健性边界**：参数在什么范围内结论不变 |
| 呈现 | 表格或曲线 + 读图解读（只给图不解读=未完成） |

**研赛加分层**：若进一步做**双参数联合扰动**或**全局灵敏度（如 Sobol 指数量级）**，并给出"结论翻转的临界条件"，属于明显优于常规做法。

## 四、按题型族的验证侧重

| 题型族 | 首选独立验证 | 灵敏度重点 |
|---|---|---|
| 信号与通信 | 与理论界（CRB 等）或实测对比 | 噪声水平、信噪比 |
| 优化与调度 | 与基线算法/松弛下界对比 | 约束右端项、需求波动 |
| 数据驱动与预测 | 交叉验证 + 时间外推验证 | 特征扰动、样本量 |
| 医学与生物 | 分层验证 + 临床合理性 | 阈值、人群差异 |
| 能源、双碳与地理 | 情景对比 + 空间交叉验证 | 权重、政策参数 |
| 评价与美学量化 | 多权重方案对比 + 一致性检验 | 权重扰动、专家差异 |
| 力学与守恒 | 守恒量检验 + 边界工况 | 材料参数、工况范围 |

## 五、输出时的证据要求

对每个问题给出：

- **位置**（章节号 + 原文片段）；
- **缺失类型**（无验证 / 验证不独立 / 误差分析空泛 / 灵敏度不完整 / 未给稳健性边界）；
- **证据**（为什么判定为缺失——需引用论文原文）；
- **补做建议**（在四天赛程内可完成的最小补做动作）。

**注意**：不得因为论文没有做到"教科书级完整"就报为严重问题。判定基准是**该题型的常规要求**，不是理想状态。
