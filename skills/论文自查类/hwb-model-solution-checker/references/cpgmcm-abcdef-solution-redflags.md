# A~F 六题型求解红线（2020—2025 真题归纳）

## A 题：信号、芯片与物理机理

| 红线 | 典型表现 |
|---|---|
| 无噪声/干扰模型直接套算法 | 声称高精度却未说明噪声假设 |
| 只给算法不给代价 | 复杂度/存储/时延/能耗分析缺失 |
| 约束漏写导致解不可行 | 硬件资源限制未转成约束 |
| 精度验证只有单点 | 应给误差随信噪比/资源变化的曲线 |
| 单位与量纲混乱 | 功率谱密度单位缺失或错误 |

**真题**：2020 芯片相噪算法设计（华为题）｜2021 相关矩阵组的低复杂度计算和存储建模（华为题）｜2022 移动场景超分辨定位问题（华为题）｜2023 WLAN 网络信道接入机制建模｜2024 风电场有功功率优化调度｜2025 通用神经网络处理器下的核内调度问题

## B 题：通信、材料与逼近建模

| 红线 | 典型表现 |
|---|---|
| 声称"改进"但不复现基线 | 提升幅度无对照 |
| 逼近题不给误差界 | 只报一组参数下的误差 |
| 组合优化不给可行性/最优性 | 声称最优却无 gap 或下界 |
| 数据清洗不交代 | 用异常值直接训练 |
| 经验公式超范围使用 | 未说明适用条件 |

**真题**：2020 汽油辛烷值建模｜2021 空气质量预报二次建模｜2022 方形件组批优化问题（华为题）｜2023 DFT 类矩阵的整数分解逼近｜2024 WLAN 组网中网络吞吐量建模｜2025 无线通信系统链路速率建模

## C 题：数据驱动、评价与医学

| 红线 | 典型表现 |
|---|---|
| 训练/测试同源 | 无独立验证或划分不当 |
| 类别不平衡未处理 | 只报准确率，不报召回/F1/混淆矩阵 |
| 评价权重无依据 | 权重凭空设定且无敏感性 |
| 医学结论无合理性讨论 | 纯黑箱输出直接给临床建议 |
| 指标口径中途变化 | 同名指标前后定义不一致 |

**真题**：2020 面向康复工程的脑电信号分析和判别模型｜2021 帕金森病的脑深部电刺激治疗建模研究｜2022 汽车制造公司涂装-总装缓存区调序调度优化问题｜2023 大规模创新类竞赛评审方案研究｜2024 数据驱动下磁性元件的磁芯损耗建模｜2025 围岩裂隙精准识别与三维模型重构

## D 题：系统、地理、能源与对抗

| 红线 | 典型表现 |
|---|---|
| 约束漏写 | 物理/工程限制未进入模型 |
| 多目标无权衡说明 | 直接加权却不说权重来源 |
| 情景设定无依据 | 双碳/路径类的情景凭空设定 |
| 空间尺度混乱 | 分辨率与结论精度不匹配 |
| 博弈规则不可计算 | 把对抗题写成文字描述 |

**真题**：2020 无人机集群协同对抗｜2021 抗胰腺癌候选药物的优化建模｜2022 PISA 架构芯片资源排布问题（中兴题）｜2023 区域双碳目标与路径规划研究｜2024 大数据驱动的地理综合问题｜2025 低空湍流监测及最优航路规划

## E 题：定位、诊断与临床信号

| 红线 | 典型表现 |
|---|---|
| 只给点估计 | 无置信区间或误差分布 |
| 误差来源未分类 | 把一切误差归给"数据噪声" |
| 特征不可解释 | 无法说明特征与物理量的对应 |
| 跨工况未验证 | 训练与测试工况差异未讨论 |
| 结果无实际意义映射 | 给出数值但不解释其工程/临床含义 |

**真题**：2020 能见度估计与预测｜2021 信号干扰下的超宽带(UWB)精确定位问题｜2022 草原放牧策略研究｜2023 出血性脑卒中临床智能诊疗建模｜2024 高速公路应急车道启用建模｜2025 高速列车轴承智能故障诊断问题

## F 题：气象、天文、交通与跨界综合

| 红线 | 典型表现 |
|---|---|
| 主观概念未可操作化 | 美学/公平类直接打分无定义 |
| 时空相关性忽略 | 按独立样本处理时空数据 |
| 守恒关系未显式 | 力学题缺守恒式 |
| 外推风险未讨论 | 预报类不做泛化评估 |
| 多目标权重随意 | 排班/物资类无权衡依据 |

**真题**：2020 飞行器质心平衡供油策略优化｜2021 航空公司机组优化排班问题｜2022 COVID-19 疫情期间生活物资的科学管理问题｜2023 强对流降水临近预报｜2024 X 射线脉冲星光子到达时间建模｜2025 江南古典园林的美学特征建模

## 六题型共用红线

| 红线 | 判据 |
|---|---|
| 结果违背物理/业务常识 | 出现不可能的量值 |
| 逐问回答有遗漏 | 题目某小问未被回答 |
| 量纲不自洽 | 等式两侧不匹配 |
| 符号与其他章节不一致 | 同一量两套符号 |
| 结果不可复现 | 无种子/参数/版本交代 |
| 出现其他题目的残留内容 | 拼凑痕迹 |
| 出现培养单位/姓名/队伍编号 | **论文无效** |
