# HWB Paper AIGC Auditor

研赛论文 **AI 痕迹审计** Skill。三层审计：表层语言 → 结构模板 → 建模真实性。

## 为什么研赛需要这个 Skill

研赛对 AI 使用的态度是**允许但要求规范**：

| 规则 | 出处 |
|---|---|
| 可使用人工智能产品，**仅作为答题的辅助工具，而非主导手段** | 《竞赛通知》（第二十一届起明确） |
| 不能代替参赛队伍的独立思考和竞赛答题的主体工作 | 同上 |
| 正文、数字模型、公式引用等**所有引用文献、引用程序（包括人工智能产品）均按规定注明来源** | 同上 |
| 专家委员会对**所有论文**进行查重，重复率高于阈值一般直接判“违规论文" | 同上 |
| 引用他人程序未标注来源，发现程序雷同按抄袭认定 | 同上 |

因此团队面对的现实问题是：**用 AI 辅助写的段落，容易留下机器腔，且与“必须注明来源“的要求冲突。**
本 Skill 的作用是帮你把这些段落找出来，**改回自己的表达**，并把使用情况如实登记。

## 三层审计

| 层 | 看什么 | 典型痕迹 |
|---|---|---|
| **L1 表层语言** | 句式与措辞 | 排比式“首先/其次/最后“、过度对称的段落、“值得注意的是“式填充、每段都“不仅…而且…" |
| **L2 结构模板** | 章节骨架 | 问题分析只是题目转述；各问分析长度高度均匀；图表全为通用示意图 |
| **L3 建模真实性** | 模型与结果 | 模型并列无融合；参数无来源；结果与代码不符；“改进“无基线 |

## 输出

1. **风险结论表**（每层风险等级 + 证据位置）
2. **高风险句清单**（精确引用 + 命中的模式 + 改写建议）
3. **模型真实性分类**（真实建模 / 模板化建模 / 模型拼装 / 伪改进 / 结论倒推）
4. **人工化修改清单**（按优先级，指向本题特有问题）
5. **与 AI 使用披露的一致性核对**
6. **HTML 报告**（若需要，使用 `templates/` 中的自包含模板）

## 明确不做的事

- ❌ 不提供“降低 AI 检测率“的方法
- ❌ 不提供“绕过查重“的方法
- ❌ 不给出"AI 生成概率“的断言（检测工具误判率高，不可靠）
- ❌ 不把“语言通顺、结构清晰“等同于 AI 痕迹
