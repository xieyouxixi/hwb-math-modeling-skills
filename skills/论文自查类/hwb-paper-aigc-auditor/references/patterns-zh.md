# 中文 AI 痕迹模式库

按“模式 → 识别特征 → 为什么算痕迹 → 改法“组织。`humanizer-keywords.txt` 收录关键词表。

## 一、句式类模式

| 模式 | 识别特征 | 为什么是痕迹 | 改法 |
|---|---|---|---|
| **排比开场** | 连续 ≥3 段以“首先/其次/再次/最后/此外“开头 | 消除段落的自然差异，无信息增量 | 删去序号词，用内容本身衔接 |
| **对称结构** | 每段都“不仅……而且……“或“一方面……另一方面……" | 结构同质化，掩盖内容轻重 | 只保留真正需要并列的地方 |
| **三段同长** | 连续段落句数相同（≥4 段） | 自然写作不会如此均匀 | 按内容重要性重排长短 |
| **总-分-总嵌套** | 每小节都是“概述→三点→小结" | 结构模板化 | 按本题逻辑重组 |
| **破折号补充** | 频繁用“——“插入解释 | 机械式补充说明 | 合并进主句或另起一句 |

## 二、措辞类模式

| 模式 | 高频词 | 为什么是痕迹 | 改法 |
|---|---|---|---|
| **空泛拔高** | 具有重要意义、提供了有力支撑、奠定了坚实基础、具有广阔的应用前景 | 无信息量，删掉语义不变 | 直接删除，或改为具体结论 |
| **提示语填充** | 值得注意的是、不难发现、需要指出的是、众所周知 | 无实际提示对象 | 删除 |
| **总结套话** | 综上所述、总而言之、由此可以看出 | 段落本身已表达该意思 | 删除或改为具体过渡 |
| **抽象名词堆叠** | 机制、维度、层面、范式、赋能、抓手、闭环 | 名词化掩盖动作主体 | 改为动词句，写清谁做什么 |
| **程度强化** | 极大地、显著地、充分地、有效地 | 无量化支撑 | 给出数值或删去 |

## 三、内容类模式（最需要警惕）

| 模式 | 识别特征 | 为什么是痕迹 | 改法 |
|---|---|---|---|
| **问题分析转述** | 分析段落可逐句对应回题目原文 | 没有产生新信息 | 加入数据规模、量纲、约束、物理机制的本题证据 |
| **模型清单** | 模型 A、B、C 并列，彼此不引用 | 堆砌，无主线 | 确定主线模型，删除未被使用的模型 |
| **参数无源** | 参数凭空出现，无估计或引用 | 无法复现，不可信 | 说明来源与估计方法 |
| **改进无基线** | 声称“改进“但无对比实验 | 无证据 | 复现基线并量化提升与代价 |
| **结果无误差** | 结果异常完美，无误差讨论 | 违背工程常识 | 补误差分类、量级估计、灵敏度 |
| **图表无针对** | 图为通用示意或默认配色 | 与本题数据无关 | 用本题数据重绘，标注量纲与关键点 |
| **结论过强** | 由模型结果直接推出政策建议 | 缺乏现实约束讨论 | 加入适用边界与前提条件 |

## 四、段落节律诊断

自然写作的段落长度呈**不规则分布**；机器生成倾向于均匀。诊断方法：

1. 统计各段句数（或字数）；
2. 计算变异系数 CV = 标准差 / 均值；
3. 判断：

| CV | 提示 |
|---|---|
| > 0.5 | 自然（长短交错） |
| 0.25—0.5 | 正常 |
| < 0.25 | 偏均匀，需结合其他证据判断 |
| < 0.15 | 高度均匀，属痕迹特征 |

> 变异系数只是**辅助指标**。不是所有均匀段落都是 AI 写的（有些作者就是写得均匀），必须结合具体模式一同判断。

## 五、标点与排版类模式

| 模式 | 识别特征 |
|---|---|
| 中英文标点混用 | 中文段落里出现 ASCII 逗号与句点 |
| 引号不统一 | 直角引号「」与弯引号""与 ASCII " 混用 |
| 全角半角混用 | 数字与单位间距不一致 |
| 列表滥用 | 正文中大段使用无必要的项目符号 |
| 缩进不一致 | 段落缩进时有时无 |

> 这类属**格式问题**，应在 `hwb-paper-format-checker` 中处理，本 Skill 只做提示，**不重复计分**。

## 六、使用注意

1. **先查内容模式（第三节），再查措辞模式**。内容问题不解决，改措辞只是化妆。
2. **模式要成组出现才可信**。单一模式命中不构成结论。
3. **不要为了“像人写的“而故意制造不规范的表达**——研赛评委看重的是严谨，而不是“看起来随机”。
4. **所有修改都应让论文更具体**：加入本题的数据、参数、物理约束、误差讨论，而不是换同义词。
