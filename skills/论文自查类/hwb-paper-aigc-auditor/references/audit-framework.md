# 审计框架与三层检测设计

## 一、设计原则

| 原则 | 说明 |
|---|---|
| **证据优先** | 每条判定必须能指到具体句子与命中的模式，不接受“整体感觉" |
| **内容优先于文体** | 语言通顺、结构清晰是优点，不是痕迹 |
| **本题特异性为准绳** | 最有效的判据是“这段内容换一道题能不能原样用" |
| **不给概率** | AI 文本检测误判率高，本框架只输出痕迹特征与风险等级 |
| **指向重写** | 所有建议的落点都是“作者自己重写 + 如实披露”，不是规避检测 |

## 二、三层结构

### L1 表层语言层

**审计对象**：句子与段落层面的书面特征。

| 子项 | 具体检查 |
|---|---|
| 句式模板 | 排比开头（首先/其次/再次/最后）、对称结构（不仅…而且…）、“三段式“段落 |
| 填充措辞 | 值得注意的是、不难发现、综上所述、具有重要意义的、提供了有力支撑、奠定了坚实基础 |
| 段落节律 | 段落长度高度均匀；每段句数相同；无长短交错 |
| 标点模式 | 破折号/冒号机械使用；括号补充说明过多；中英文标点混用无规律 |
| 词汇密度 | 反复使用同一批抽象名词（机制、维度、层面、范式、赋能） |
| 评价句式 | 结尾一律拔高（“为……提供了……“） |

**风险分级**：

| 等级 | 判据 |
|---|---|
| 高 | 同一模式在连续 3 段以上出现，或全篇出现 ≥ 8 次 |
| 中 | 全篇出现 4—7 次，或集中在某一章 |
| 低 | 出现 1—3 次，且不构成节律特征 |

### L2 结构模板层

**审计对象**：章节骨架与图文组织。

| 子项 | 检查 |
|---|---|
| 骨架通用性 | 把题目名称替换成另一道题，章节能否原样成立 |
| 问题分析的针对性 | 是否出现本题特有的数据规模、量纲、约束、物理机制 |
| 各问分析均衡度 | 各问分析段落长度差异是否 < 10%（过度均匀是痕迹） |
| 图表针对性 | 图是否为通用示意图；配色是否默认；坐标轴是否为占位符 |
| 公式来源 | 公式是否只是“摆出“而无推导或不引用具体条件 |
| 章节比例 | 是否符合研赛常见比例（模型建立与求解 ≥ 50%） |

**模板化程度评级**：

| 等级 | 判据 |
|---|---|
| 低 | 骨架由本题任务结构决定，多处体现本题特有内容 |
| 中 | 骨架通用，但各章有本题特有内容 |
| 高 | 骨架通用且各章内容空泛，替换题目名称后仍成立 |

### L3 建模真实性层

**审计对象**：模型、参数、结果与创新点的实质。

| 子项 | 检查 |
|---|---|
| 主线 | 全文是否有 1—2 个主线模型贯穿各问 |
| 模型使用率 | 引入的模型是否都在后续被使用（未使用者=拼装） |
| 参数来源 | 每个参数是否说明来源（数据估计/文献取值/网格搜索） |
| 结果一致性 | 正文数值与代码/附件输出是否一致 |
| 验证独立性 | 是否用留出集/交叉验证/物理合理性/基线对比（而非训练误差） |
| 误差讨论 | 是否有误差来源分类与量级估计 |
| 灵敏度 | 是否给出关键参数扰动与**结论翻转临界条件** |
| 改进真实性 | "改进“是否有基线复现与代价评估 |

**真实性分类**：`真实建模 / 模板化建模 / 模型拼装 / 伪改进 / 结论倒推`。

## 三、交叉验证原则

三层之间不独立。典型关联：

| L3 发现 | 对应的 L1/L2 表现 |
|---|---|
| 模型拼装 | 各模型段落句式雷同（同一模板生成） |
| 伪改进 | "创新点“段落充满拔高评价而无数值 |
| 结论倒推 | 结果段落异常整齐，无误差讨论 |
| 模板化建模 | 骨架通用、问题分析只是转述 |

因此**建议三层同时报告**，而不是只报 L1 的语言痕迹——只改语言不改内容，问题依然存在。

## 四、输出规范

| 要求 | 说明 |
|---|---|
| 位置 | 精确到章节号或原文片段 |
| 证据 | 逐字引用，不得改写 |
| 模式 | 指明命中的模式名（如“排比开头“） |
| 风险 | 低/中/高 + 判据 |
| 建议 | 可执行的动作，且应指向本题特有内容 |
| 边界 | 每份报告结尾必须写明“不构成 AI 生成概率判定" |

## 五、误判防范

以下情况**不得**判为 AI 痕迹：

| 情况 | 理由 |
|---|---|
| 术语使用规范统一 | 这是写作素养 |
| 图表编号规范、参考文献体例统一 | 这是格式规范 |
| 结构清晰、分段合理 | 这是可读性 |
| 使用“首先/其次“表达真实的先后顺序 | 有语义必要性，不算填充 |
| 摘要五要素齐备 | 这是研赛的明确要求 |

**判据**：只有当某个模式出现频率高、无信息增量、且删除后语义不变时，才判为痕迹。
