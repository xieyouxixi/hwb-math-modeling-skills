# L1 表层语言 · 增强检测细则

本文件把 L1 的检查动作细化到可自动化或半自动化的程度。

## 一、段落节律检测

### 指标

| 指标 | 计算 | 判读 |
|---|---|---|
| 段长变异系数 CV | 标准差 / 均值（按字数） | < 0.25 偏均匀；< 0.15 高度均匀 |
| 段首词重复率 | 相同段首词出现次数 / 段落总数 | > 0.4 可疑 |
| 段末句模式重复率 | 以相同套话结尾的段落占比 | > 0.3 可疑 |
| 句长分布 | 句长标准差 / 均值 | 过小则节律机械 |

### 排查顺序

1. 先算 CV；
2. 若 CV < 0.25，再看段首词重复率；
3. 两者同时偏高 → 判定为结构痕迹；
4. 若 CV 正常但段首重复率高 → 只报段首问题。

## 二、连接词密度

统计`首先 / 其次 / 再次 / 最后 / 此外 / 与此同时 / 另一方面 / 在此基础上 / 进一步地`的出现次数与分布。

| 情形 | 判读 |
|---|---|
| 单段内 ≥ 3 个 | 该段为模板结构 |
| 连续 3 段均以这类词开头 | 全篇排比结构，高风险 |
| 全篇 ≥ 8 次 | 中风险 |
| 出现在真实顺序描述中（如“首先读取数据，其次标准化“） | 可接受 |

## 三、标点与符号统计

| 指标 | 异常阈值 |
|---|---|
| 破折号（——）频次 | 每千字 > 2 次 |
| 冒号引出解释的频次 | 每千字 > 3 次 |
| 括号补充说明频次 | 每千字 > 4 次 |
| 全角/半角混用 | 出现即记录（归格式问题） |
| 引号类型混杂 | 出现即记录 |

## 四、句式模板匹配

用正则或句式骨架匹配以下模板：

```text
不仅……而且……
一方面……另一方面……
既……又……
随着……的不断发展，……越来越……
在……背景下，……具有重要意义
针对……问题，本文提出了……
为……提供了……支撑
通过……，实现了……
在……方面，具有……优势
```

命中处理：

| 数量 | 判读 |
|---|---|
| 任一模板 ≥ 3 次 | 该模板已成套路，逐处检查必要性 |
| 合计 ≥ 10 次 | 全篇句式模板化，需整体改写 |

## 五、抽象名词密度

统计`机制/维度/层面/范式/赋能/抓手/闭环/生态/路径/体系/格局/逻辑/协同/联动`等词的每千字频次。

| 每千字频次 | 判读 |
|---|---|
| < 3 | 正常 |
| 3—6 | 偏多，检查是否有具体指代 |
| > 6 | 高度可疑，抽象化写作 |

**注意**：这些词在部分领域是必要术语（如“机制“在机理建模中），必须结合具体句子判断，不得机械删除。

## 六、可自动化部分与人工判断部分

| 可自动化 | 需人工判断 |
|---|---|
| 段长统计与 CV | 段落划分是否合理 |
| 频次统计（关键词表） | 该词是否有信息增量 |
| 句式模板正则匹配 | 该句式是否有语义必要性 |
| 标点频次 | 是否符合当年模板要求 |
| 引号/标点类型统计 | 是否属格式问题（转 format-checker） |

## 七、输出格式

```markdown
## L1 审计结果

### 指标概览
| 指标 | 实测值 | 阈值 | 判读 |

### 命中模式明细
| 模式 | 出现次数 | 分布 | 风险 | 代表位置 |

### 高风险段落清单
| 位置 | 原文（逐字） | 命中模式 | 改写建议 |
```

## 八、边界

- 本层只输出**痕迹特征**，不输出"AI 生成概率”。
- 检测结果受论文文体影响：综述型章节天然高频使用连接词，不应与建模章节同标准。
- 若某项指标异常但人工判断认为有语义必要性，应以人工判断为准，并在报告中说明理由。
