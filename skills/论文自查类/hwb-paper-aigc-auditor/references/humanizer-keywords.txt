## 九、使用方式

```bash
# 统计频次（示例）
python - <<'PY'
import re, collections
kw = [l.strip() for l in open('humanizer-keywords.txt', encoding='utf-8')
      if l.strip() and not l.startswith('#')]
text = open('论文.txt', encoding='utf-8').read()
c = collections.Counter()
for k in kw:
    n = text.count(k)
    if n:
        c[k] = n
for k, n in c.most_common(40):
    print(f'{n:>4}  {k}')
PY
```

## 十、判定阈值参考

| 情形 | 提示 |
|---|---|
| 单个词出现 ≥ 5 次 | 高度可疑，逐处检查是否有信息增量 |
| 同一类词合计 ≥ 15 次 | 该类的写作已成模板，需整体重写 |
| 某词集中在一章内 | 该章可能由同一模板生成 |
| 某词出现在各章均匀分布 | 全篇写作风格模板化 |

## 十一、边界

- 关键词只是**线索**，不是结论。必须回到具体句子判断是否删去后语义不变。
- 学术写作中“首先/其次“有时是真实顺序，“机制“有时是必要术语，不得一律删除。
- **禁止**把本表用作“规避 AI 检测“的替换词库。正确做法是重写内容，使其更具体、更有本题特色。
