# 与第三方 AI 文本检测工具的配合与局限

## 一、基本立场

外部 AI 文本检测工具的**结论不能作为定论**。原因：

| 局限 | 说明 |
|---|---|
| 误判率高 | 结构规范、语言流畅的学术文本常被误判为 AI 生成 |
| 不稳定 | 同一文本多次检测结果可能不同；微调措辞即可显著改变分数 |
| 不可解释 | 不给具体依据，无法指导修改 |
| 对中文与学术文体适应性差 | 训练语料与目标文本分布存在差距 |
| 非官方 | 研赛官方使用的是**相似度检测（查重）**，不是 AI 文本检测 |

因此本 Skill 的定位是**用可解释的痕迹特征替代黑箱分数**。

## 二、研赛官方查重与第三方检测的区别

| | 研赛官方 | 第三方 AI 检测工具 |
|---|---|---|
| 检测对象 | 论文**相似度**（与他人的重复） | 文本是否由 AI 生成 |
| 判定后果 | 高于阈值一般直接判**违规论文** | 无官方效力 |
| 依据 | 专家委员会确定的阈值 | 不公开 |
| 正确应对 | **自己写、规范引用、如实披露** | 不应作为修改目标 |

**关键**：研赛查重针对的是**重复**，不是"AI 味”。所以把精力放在“降低 AI 检测率“上是方向性错误——真正需要做的是**降低与他人文本的重复**并**如实披露 AI 使用**。

## 三、若已获得第三方检测报告

可以把它作为**参考输入之一**，但必须：

1. 不把其分数作为“是否 AI 生成“的结论；
2. 不以其分数为优化目标；
3. 用它定位“被标记的段落”，再**用本 Skill 的三层框架**独立复核；
4. 在报告中说明该工具的局限。

### 处理流程

```text
第三方报告标记高分段
        ↓
本 Skill 独立复核（L1/L2/L3）
        ↓
   ┌────┴────┐
确认为痕迹        未发现痕迹
   ↓                ↓
用自己话重写   说明可能是误判
（加入本题特有内容）  （保留原表述）
        ↓
如实登记 AI 使用并披露
```

## 四、绝不允许的用法

| 请求 | 处理 |
|---|---|
| "帮我降低 AI 检测率" | **拒绝**。说明正确做法是自己重写并如实披露 |
| "帮我绕过查重" | **拒绝**。违反学术诚信，且研赛明确禁止论文送第三方查重 |
| "把这句换成不那么像 AI 的说法（但意思不变）" | **拒绝纯同义词替换**。建议改为加入本题特有的数据与物理约束 |
| "告诉我哪个检测工具更松" | **拒绝**。与合规目标无关 |

## 五、推荐的替代做法

若目标是“让论文更像自己的作品”，正确路径是：

| 步骤 | 动作 |
|---|---|
| 1 | 把机器腔段落**重写为具体叙述**：写清本题的数据规模、量纲、约束、物理机制 |
| 2 | 删去无信息增量的填充词与拔高评价 |
| 3 | 把“模型清单“整理为有主线的模型体系 |
| 4 | 补基线对比与代价评估，使“改进“落地 |
| 5 | 补误差分类、量级估计与灵敏度分析 |
| 6 | 在 `hwb-ai-usage-disclosure` 中**如实登记** AI 使用情况 |

**这六步做完，论文的"AI 味“自然下降，因为它变得具体了；同时合规性也解决了。**

## 六、边界声明

- 本文件不推荐、不评价任何具体的第三方检测产品。
- 本 Skill 不输出"AI 生成概率”。
- 最终判断应由作者与指导教师人工复核。
