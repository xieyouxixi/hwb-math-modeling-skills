# A~F 六题型逐题检查点（2020—2025 真题归纳）

使用方式：先由 `hwb-problem-translator` 判定题型族，再按下表逐项核对问题分析章节。

## A 题：信号、芯片与物理机理

| 检查点 | 期望在分析章节看到 |
|---|---|
| 噪声/干扰是否被建模 | 明确写出噪声类型与统计假设，而非跳过 |
| 资源代价是否被提及 | 复杂度、存储、时延、能耗等至少出现一项 |
| 硬件约束是否被翻译 | 片上存储、并行度、精度限制被转成不等式约束 |
| 精度指标是否明确 | 给出评价精度的方法（RMSE、CRB、误差分布） |
| 主线是否含"机理 + 优化" | 只做优化不做机理，或反之，都算单薄 |

**真题锚点**：2020 芯片相噪算法设计（华为题）、2021 相关矩阵组的低复杂度计算和存储建模（华为题）、2022 移动场景超分辨定位问题（华为题）、2023 WLAN 网络信道接入机制建模、2024 风电场有功功率优化调度、2025 通用神经网络处理器下的核内调度问题。

## B 题：通信、材料与逼近建模

| 检查点 | 期望在分析章节看到 |
|---|---|
| 基线是否被识别 | 题目若含"二次建模/改进"，分析中须点出基线是什么 |
| 精度–代价权衡是否被提出 | 逼近/压缩类题必须讨论权衡 |
| 数据清洗思路是否提出 | 有实测数据表时须提出清洗方向 |
| 组合规模是否被估计 | 整数规划类须说明规模与求解可行性 |
| 表达式来源是否清晰 | 经验公式须说明适用条件 |

**真题锚点**：2020 汽油辛烷值建模、2021 空气质量预报二次建模、2022 方形件组批优化问题（华为题）、2023 DFT 类矩阵的整数分解逼近、2024 WLAN 组网中网络吞吐量建模、2025 无线通信系统链路速率建模。

## C 题：数据驱动、评价与医学

| 检查点 | 期望在分析章节看到 |
|---|---|
| 指标是否可操作化 | 抽象概念（美学、创新性、风险）必须给出量化路径 |
| 权重来源是否提出 | 评价类题须说明权重从何而来 |
| 划分策略是否提出 | 数据驱动题须声明训练/验证策略 |
| 类别不平衡是否被识别 | 分类题须指出正负样本比例问题 |
| 医学/生物合理性是否被预设 | 结果讨论须预留合理性分析 |

**真题锚点**：2020 面向康复工程的脑电信号分析和判别模型、2021 帕金森病的脑深部电刺激治疗建模研究、2022 汽车制造公司涂装-总装缓存区调序调度优化问题、2023 大规模创新类竞赛评审方案研究、2024 数据驱动下磁性元件的磁芯损耗建模、2025 围岩裂隙精准识别与三维模型重构。

## D 题：系统、地理、能源与对抗

| 检查点 | 期望在分析章节看到 |
|---|---|
| 约束表是否先于优化 | 物理系统题必须先列约束再谈目标 |
| 情景设定是否提出 | 双碳/路径类题须定义情景 |
| 空间/尺度是否说明 | 地理类题须说明空间分辨率与边界 |
| 收益/代价函数是否定义 | 对抗/博弈类题须把规则转成可计算函数 |
| 多目标如何权衡 | 多目标题须说明处理方式（加权/帕累托） |

**真题锚点**：2020 无人机集群协同对抗、2021 抗胰腺癌候选药物的优化建模、2022 PISA 架构芯片资源排布问题（中兴题）、2023 区域双碳目标与路径规划研究、2024 大数据驱动的地理综合问题、2025 低空湍流监测及最优航路规划。

## E 题：定位、诊断与临床信号

| 检查点 | 期望在分析章节看到 |
|---|---|
| 误差来源是否分类 | 数据误差/模型误差/数值误差分开谈 |
| 不确定性如何量化 | 必须提出区间或分布，不能只给点估计 |
| 特征可解释性是否提出 | 诊断类题须说明特征与物理量的对应 |
| 跨工况泛化是否被考虑 | 训练与测试工况差异须说明 |
| 临床/工程合理性是否预留 | 结果须能映射回实际含义 |

**真题锚点**：2020 能见度估计与预测、2021 信号干扰下的超宽带(UWB)精确定位问题、2022 草原放牧策略研究、2023 出血性脑卒中临床智能诊疗建模、2024 高速公路应急车道启用建模、2025 高速列车轴承智能故障诊断问题。

## F 题：气象、天文、交通与跨界综合

| 检查点 | 期望在分析章节看到 |
|---|---|
| 主观概念是否被定义 | 美学/公平/体验类须给出可测定义 |
| 时空特性是否说明 | 气象/交通类须说明时空相关结构 |
| 守恒关系是否显式 | 力学类须写出守恒式作为硬约束 |
| 多目标权重来源 | 排班/物资类须说明权衡依据 |
| 泛化与不确定性 | 预报类须讨论外推风险 |

**真题锚点**：2020 飞行器质心平衡供油策略优化、2021 航空公司机组优化排班问题、2022 COVID-19 疫情期间生活物资的科学管理问题、2023 强对流降水临近预报、2024 X 射线脉冲星光子到达时间建模、2025 江南古典园林的美学特征建模。

## 通用红线（六题型共用）

| 红线 | 判据 |
|---|---|
| 分析章节出现最终数值结果 | 越界（属结果章节） |
| 分析章节重复题目原文超过 1 段 | 与问题重述重复 |
| 引入模型但后续未使用 | 模型堆砌 |
| 宣称"数据质量良好"却未给出任何统计 | 无根据判断 |
| 承诺的分析动作未兑现 | 承诺落空 |
| 出现培养单位/姓名/队伍编号 | **论文无效** |
