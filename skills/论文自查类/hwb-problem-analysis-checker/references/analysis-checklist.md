# 问题分析检查清单

## A. 任务映射

| # | 检查项 | 通过标准 |
|---|---|---|
| A1 | 赛题每一问都有对应分析段落 | 问数与分析段落数匹配 |
| A2 | 每问的分析包含"要什么 → 难点在哪 → 打算怎么入手" | 三段式完整 |
| A3 | 附属要求（如"并给出评价""并讨论"）被发现并分析 | 逐条对应 |
| A4 | 未把不同问混在一起分析 | 逐问独立 |
| A5 | 分析顺序与赛题问序一致 | 顺序一致（便于评委对照） |

## B. 数据推理

| # | 检查项 | 通过标准 |
|---|---|---|
| B1 | 说明了数据的规模与结构 | 给样本量、字段数、时间范围 |
| B2 | 说明了数据的质量状况 | 缺失、异常、量纲混用等 |
| B3 | 数据特征与选模相关 | 如"特征间相关性高 → 考虑降维/正则化" |
| B4 | 未出现与附件不符的描述 | 抽样核对 3 处数据描述 |
| B5 | 未越界做数据预处理细节 | 清洗算法细节应在数据预处理章节 |

## C. 选模依据

| # | 检查项 | 通过标准 |
|---|---|---|
| C1 | 每个模型的引入都有理由 | 理由可检验（机理/数据/对比），非"因为常用" |
| C2 | 说明了候选方案之间的取舍 | 至少有"为何不选另一方案"的简短说明 |
| C3 | 理由与题目场景相连 | 不是通用教科书式陈述 |
| C4 | 未出现"模型清单式堆砌" | 引入的每个模型在后续章节都被真正使用 |

## D. 跨问联动

| # | 检查项 | 通过标准 |
|---|---|---|
| D1 | 说明了问题之间的依赖关系 | 有依赖图或文字说明 |
| D2 | 说明了主线模型如何贯穿 | 能一句话概括主线 |
| D3 | 前问结果如何支撑后问 | 显式说明传递内容 |
| D4 | 误差/不确定性如何向后传播 | 有交代或至少在假设中声明 |

## E. 承诺兑现（回溯检查）

| # | 检查项 | 通过标准 |
|---|---|---|
| E1 | 分析中承诺的分析动作在后续章节出现 | 如"将做灵敏度分析"→ 后续确实有 |
| E2 | 分析中提到的方法在模型章节出现 | 无"提了没做" |
| E3 | 模型章节的方法在分析中有预告 | 无"突然出现" |
| E4 | 摘要中的方法体系与分析一致 | 三处一致 |

## F. 边界与篇幅

| # | 检查项 | 通过标准 |
|---|---|---|
| F1 | 未重复问题重述内容 | 复述题目段落不超过 1 段 |
| F2 | 未提前写结果 | 不出现最终数值结果 |
| F3 | 篇幅合理 | 一般不短于 1 页、不长于 3 页 |
| F4 | 匿名合规 | 无培养单位/姓名/队伍编号 |
| F5 | 章节标题层级符合当年官方模板 | 层级正确 |

## 输出要求

对每个不通过项给出：

- **位置**（章节号 + 原文片段）；
- **问题类型**（A—F 分类）；
- **为什么是问题**（对评阅的影响）；
- **具体修改建议**（可执行的一句话动作）。

无法核验的项目（如看不到附件）写入"待核对事项"，不得猜测。
