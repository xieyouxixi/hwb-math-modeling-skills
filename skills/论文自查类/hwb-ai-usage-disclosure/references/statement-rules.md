# AI 工具使用声明撰写规则

## 一、声明要回答的四个问题

一份合格的声明必须让评委在 30 秒内回答：

1. **用没用**？（用了 / 没用）
2. **用在哪**？（哪些环节，边界在哪）
3. **怎么用**？（辅助到什么程度，人做了什么）
4. **谁负责**？（结论由谁承担）

## 二、总体说明段（必写）

固定要素：

- 明确"使用/未使用"；
- 一句话界定用途范围（例如"仅用于代码调试与文献检索辅助"）；
- 一句话界定**未参与**的部分（例如"问题理解、模型选择、核心推导、结果判断与结论形成均由本队独立完成"）；
- 一句话责任归属（例如"论文全部内容由参赛队员独立完成并负责"）。

**句式示例（辅助型）**：

> 本队在竞赛过程中使用了人工智能产品作为辅助工具，用途限于代码语法调试、文献线索检索与英文摘要语言润色。赛题理解、模型选择与建立、核心推导、参数确定、结果分析与结论形成均由本队三名队员独立完成，人工智能产品未参与上述环节，亦未作为答题的主导手段。论文全部内容由参赛队员独立完成并负责。

**句式示例（未使用）**：

> 本队在竞赛全过程中未使用任何人工智能产品，赛题理解、数据预处理、模型建立与求解、结果分析与论文撰写均由本队队员独立完成。

## 三、使用清单（使用了才写）

| 列 | 填写要求 |
|---|---|
| 序号 | 连续编号 |
| 使用环节 | 用**论文环节名**，如"数据预处理""代码调试""摘要语言润色""文献线索检索" |
| 工具名称 | 写真实产品名，不写"某 AI 工具" |
| 版本/时间 | 尽量具体到日期；无法确定的写"使用时段约为竞赛第 N 天" |
| 用途 | 一句话，动词开头（如"排查 Python 报错"） |
| 产出物 | 具体到形态（如"修正了 3 处语法错误""给出了 2 篇文献线索"） |
| 人工修改程度 | `未采用 / 参考后重写 / 小改后采用 / 直接采用（需说明合理性）` |
| 论文对应位置 | 章节号或文件名，使其可核查 |

## 四、辅助性边界说明（最关键的一节）

这一节是评委判断"是否以 AI 为主导"的直接依据。必须**具体列举** AI 未参与的环节，且这些环节要与论文的核心贡献对应：

| 论文核心贡献 | 是否由人完成 | 说明 |
|---|---|---|
| 赛题理解与任务分解 | 是 | |
| 模型选择与建立 | 是 | |
| 核心公式推导 | 是 | |
| 参数确定与调优 | 是 | |
| 结果合理性判断 | 是 | |
| 结论与建议形成 | 是 | |
| 文字组织与排版 | 部分参考工具 | |

若其中任何一项实际是由 AI 主导完成的，**必须如实标注**，并说明人工复核了什么。**不得为了显得合规而在这一节作虚假陈述。**

## 五、语言与格式

| 要求 | 说明 |
|---|---|
| 人称 | 用"本队"，不用"我们" |
| 时态 | 过去时陈述已发生的事 |
| 措辞 | 客观、无辩解语气；不写"但是 AI 只是辅助"这种自我辩护 |
| 长度 | 总体说明 100—200 字；边界说明以表格为主 |
| 匿名 | 不出现培养单位、姓名、队伍编号、账号信息 |
| 位置 | 按当年官方模板要求放置（通常在正文指定位置或附件"支撑材料-AI 工具使用详情"） |

## 六、常见错误

| 错误 | 为什么错 | 正确做法 |
|---|---|---|
| 只写"使用了 AI 辅助" | 无法判断边界 | 拆到环节级 |
| 把 AI 生成正文写成"语言润色" | 虚假披露 | 如实写"辅助生成初稿，队员重写并核实" |
| 列出未使用的工具 | 不可核查 | 只列实际使用项 |
| 出现工具账号/邮箱 | 违反匿名 | 全部删除 |
| 与论文版本不一致 | 声明提到的工作在论文里找不到 | 论文定稿后重新核对 |
| 通篇辩解"AI 不影响原创性" | 反而引发怀疑 | 只陈述事实与边界 |
