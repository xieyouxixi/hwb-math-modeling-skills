# AI 工具使用详情模板

研赛的支撑材料中通常设有"AI 工具使用详情"栏位（若当年模板提供）。本模板给出可直接套用的结构。

## 完整模板

```markdown
# AI 工具使用详情

## 0 基本信息
| 项目 | 内容 |
|---|---|
| 赛题题号 | <A / B / C / D / E / F> |
| 使用 AI 的队员数 | <1—3> |
| 使用时段 | <竞赛第 N 天 第 M 小时>（不写具体身份信息） |

## 1 使用概览
| 序号 | 环节 | 工具 | 用途类别 | 产出物形态 | 人工修改程度 |
|---|---|---|---|---|---|
| 1 | 数据预处理 | <工具名> | C4 | Python 清洗脚本 | 参考后重写 |
| 2 | 代码调试 | <工具名> | C3 | 修正报错 | 小改后采用 |
| 3 | 英文摘要润色 | <工具名> | C1 | 摘要英文版 | 小改后采用 |

## 2 逐条详情

### 2.1 记录 1：<环节名>

- **背景**：遇到的问题是什么（一句话）。
- **请求方式**：向工具提出的问题概要（**不要粘贴完整赛题原文**，避免赛题内容外泄）。
- **获得产出**：工具给出了什么（脚本片段 / 报错原因 / 文献线索 / 文字段落）。
- **人工处理**：队员做了哪些修改与核实（具体到"改写了哪几个函数""逐句核对了哪些结论"）。
- **最终去向**：产出在论文中的位置（章节号 / 代码文件名 / 图表编号）。
- **验证方式**：如何确认该产出正确（复核计算 / 交叉检验 / 与已有结果对比）。

### 2.2 记录 2：<环节名>

（同上结构）

## 3 AI 未参与的核心环节
| 环节 | 说明 |
|---|---|
| 赛题理解与任务分解 | 由队员独立完成 |
| 模型选择与建立 | 由队员独立完成 |
| 核心公式推导 | 由队员独立完成，详见正文第 N 章 |
| 参数确定 | 由队员通过 <方法> 确定 |
| 结果分析与结论 | 由队员独立完成 |

## 4 引用注明情况
| 论文位置 | 引用的 AI 产出 | 注明方式 |
|---|---|---|
| 正文 3.2 节 | 代码片段 | 已在脚注注明来源 |
| 参考文献 [N] | 工具名称 | 已列入参考文献 |

## 5 责任声明
本队确认上述披露内容真实完整。论文全部内容由参赛队员独立完成并负责，人工智能产品仅作为辅助工具使用，未作为答题的主导手段。
```

## 填写要点

| 要点 | 说明 |
|---|---|
| 不要粘贴赛题原文 | 请求概要即可。把完整赛题交给外部服务存在泄露风险，也违反竞赛纪律 |
| 产出物要具体 | "给出了 3 处语法错误修正"优于"帮助写代码" |
| 人工处理要具体 | "重写了清洗逻辑并自行确定了缺失值处理策略"优于"做了修改" |
| 逐条给验证方式 | C3 及以上类别**必须**有验证方式，否则该条披露不完整 |
| 位置可核查 | 论文位置要写到章节号或文件名 |

## 精简版（仅 C1/C2 时）

若使用仅限语言润色与文献线索，可大幅精简：

```markdown
# AI 工具使用详情

本队在竞赛中使用了人工智能产品作为辅助工具，用途仅限于：
1. 英文摘要语言润色（竞赛第 3 天）；
2. 术语定义与文献线索检索（竞赛第 1 天），检索所得文献均已自行查阅原文核实。

以上两项产出均经队员逐句校读或核实后使用。赛题理解、模型建立、核心推导、结果分析与结论形成均由本队队员独立完成，全部内容由参赛队员负责。
```

## 禁止事项

- 不得填写未发生的使用记录；
- 不得漏写已发生的 C4—C6 类使用；
- 不得出现工具账号、邮箱、姓名、培养单位、队伍编号；
- 不得把"未使用"写成"使用了"（反之亦然）；
- 详情中的论文位置必须与定稿版本一致。
