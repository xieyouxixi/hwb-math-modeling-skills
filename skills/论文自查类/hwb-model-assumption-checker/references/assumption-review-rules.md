# 模型假设审查规则

## 一、为什么研赛的假设审查更严

研赛四天赛程、集中评审更细致，评委有足够时间核对"假设 → 模型"的传导链。常见致命写法是：假设列了 8 条，模型部分只用到了 2 条，其余 6 条永远不再出现。这会被直接读成"凑数"，且暴露作者没有真正想清楚模型边界。

## 二、假设的四个合格标准

| 标准 | 合格 | 不合格 |
|---|---|---|
| **必要** | 删掉它模型无法建立或求解 | 删掉它模型照样成立（僵尸假设） |
| **合理** | 符合工程/物理常识，或给出支持依据 | 假设"误差可以忽略"却不给数量级论证 |
| **相容** | 与附件数据一致 | 假设样本独立，但数据是同一设备连续采集 |
| **被用** | 在模型建立/求解/误差分析中被显式引用 | 全篇只出现一次 |

## 三、必要性判定方法

对该假设做删除实验：

1. 把它从假设清单里删掉；
2. 走一遍模型建立与求解，看哪一步会不成立；
3. 若无需任何补偿即可完成模型 → **僵尸假设**，建议删除或合并；
4. 若需要补充别的假设才能完成 → 说明它是必要假设，但可能需要重新表述得更精确。

## 四、六类常见问题

### 4.1 僵尸假设

**表现**：假设 3 写"假设环境温度恒定"，但模型里没有任何地方用温度；假设 5 写"忽略空气阻力"，但模型不含空气阻力项。

**修改**：删除；或把"忽略空气阻力"改为在含阻力项的一般式后加一句"因本题速度范围 [a,b] 下阻力项量级约 1e-3，故忽略"，即在**模型建立处**说明，而不是在假设处孤悬。

### 4.2 循环论证假设

**表现**："假设各变量之间相互独立" → 但模型建立的正是一个利用变量间相关性的回归。

**修改**：要么改模型，要么改假设。二者不能并存。

### 4.3 与数据冲突的假设

**表现**：假设"数据无缺失"，但附件里明显有空值。

**修改**：改为"附件数据存在少量缺失，本文采用 XX 方法处理"，并把它移到数据预处理章节作为处理说明，而非假设。

### 4.4 过度简化假设

**表现**："假设系统为线性时不变系统"，而题目场景明显含非线性（饱和、阈值）。

**修改**：给出线性化的**适用区间**论证，或改用分段/非线性模型。

### 4.5 隐含假设未声明

**表现**：模型用了高斯噪声假设、用了各态历经假设，但假设章节只字未提。

**修改**：补齐隐含假设。**这一类是最容易被忽略的扣分点**，因为评委看模型时会反问"你凭什么这么假设"。

### 4.6 假设之间互相矛盾

**表现**：假设 2"忽略摩擦"与假设 6"摩擦系数为定值 k"并存。

**修改**：合并或删一留一。

## 五、研赛特定场景的假设清单

| 题型族 | 必须考虑声明的假设 |
|---|---|
| 信号与通信 | 噪声类型与统计特性；信道模型假设；采样与量化误差假设 |
| 优化与调度 | 约束的完整性；数据确定性与不确定性；可行域非空假设 |
| 数据驱动与预测 | 训练/测试同分布；样本独立性；缺失机制（随机缺失 vs 非随机缺失） |
| 医学与生物 | 样本代表性；测量误差；混杂因素控制 |
| 能源、双碳与地理 | 边界范围；时间尺度；政策情景外生性 |
| 评价与美学量化 | 指标可加性；专家/问卷信度；权重分配的合理性 |
| 力学与守恒 | 守恒关系成立范围；材料/介质均一性；准静态假设 |

## 六、假设的表述规范

| 要求 | 示例 |
|---|---|
| 逐条编号 | "假设 1：……" |
| 客观陈述 | "假设……"而非"我们认为……" |
| 无歧义 | 避免"大致""可能""一般情况下" |
| 可检验 | 尽量写明成立条件或依据 |
| 与符号表衔接 | 假设中出现的符号须在符号说明中定义 |

## 七、输出时的证据要求

对每一条假设，输出必须包含：

- **原文**（精确引用）；
- **问题类型**（僵尸/循环/冲突/过度简化/隐含遗漏/矛盾）；
- **证据**（在论文第几章第几节找不到它的使用；或与附件哪一列数据冲突）；
- **修改建议**（删除 / 改写 / 移到其他章节 / 补充论证）。

写不出证据的结论一律降级为"优化建议"，不得作为"重要问题"报出。
