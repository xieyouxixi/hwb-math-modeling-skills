# 论文各板块详细说明文档

本目录汇总“华为杯”论文**各章节的写作规范与自查要点**，是 `hwb-...` 章节自查类 Skill 的规则来源。

> 与参考型资料库不同，本目录**不复制 Word/PDF 附件**，而是把每个板块的规范整理为**可直接被 Skill 读取的 Markdown 说明**，并给出对应的官方文件获取路径与自查工具。

## 一、论文整体结构（研究生赛模板顺序）

按官方《论文模板》，论文页面顺序为：

```text
第 1 页   封皮页（官方模板，含团队信息与 4 个图标，不可删除、图标不可替换）
第 2 页起 摘要页（官方统一摘要页，不超过 2 页）
其后      正文（严禁插入目录）
文末      参考文献、附录
另附      支撑材料 / 附件压缩包（题号+队伍编号.rar，≤50 MB，可选）
```

**硬约束速查**：

| 约束 | 要求 | 违反后果 |
|---|---|---|
| 文件格式 | 必须为 PDF，不得压缩 | — |
| 文件命名 | `题号+队伍编号`，如 `A24000010001.pdf` | — |
| 封皮页 | 首页，含团队信息与 4 个图标，不可删除/替换 | 视为不合规 |
| 匿名 | **除首页外，任何页面不得出现单位、参赛人员姓名、队伍编号** | **论文无效** |
| 摘要页 | 使用官方统一摘要页，含五要素，**不超过 2 页** | 扣分/不合规 |
| 目录 | **全文严禁出现目录** | 违规风险 |
| 附件 | `题号+队伍编号.rar`，**≤50 MB**，可选 | 超限无法提交 |

## 三、各板块写作要点（摘要版）

### 摘要（不超过 2 页）

必须包含官方要求的五要素，并做到**脱离正文可独立阅读**：

1. **建模思路**——把实际问题抽象成什么数学问题，为什么这样抽象；
2. **主要方法**——用了哪些方法/算法，各自解决哪一问；
3. **模型**——核心模型是什么，关键假设与参数；
4. **结果与结论**——给出**具体数值结果**，不是“取得了较好效果”；
5. **创新点**——哪一点是超出常规套路的。

常见失分：只描述做了什么、不给出结果；罗列模型名称但不说为什么需要；摘要里出现单位/姓名/队伍编号。

### 第一章 问题重述

三个子部分：**问题背景、问题回顾、研究综述**。

- 背景要**简洁**，不要大段抄题或写科普；
- 问题回顾要**准确还原六问的任务与约束**，不得改变条件、不得遗漏小问；
- 研究综述要有**真实文献**，且要与本题相关；引用需在参考文献中对应。
- 禁止把本应在问题分析、模型建立中的内容提前写到这里。

### 第二章 问题分析

这是区分度很高的一章，写得好能显著提升评阅印象。

- **任务映射**：每问到底要输出什么（数值？方案？模型？）；
- **数据逻辑**：数据从哪来、有哪些字段、质量如何、需要怎样预处理；
- **模型选择依据**：为什么用这个模型，更简单的模型为何不够；
- **跨问联动**：第几问的结果会成为后一问的输入，形成完整研究链。

六问必须构成**一条研究链**，而不是六个互不相干的片段——这是研究生赛评审的重点关注之一。

### 第三章 模型假设

- 每条假设都要**必要**（不用它模型不成立）、**现实**（有依据）、**被后文真正使用**；
- 假设要区分“题目给定的条件”与“我们额外引入的简化”；
- 常见的无效假设：“假设数据真实可靠”“假设模型正确”——没有信息量。

### 第四章 符号说明

- 符号表 ≠ 首次定义。**每个非通用符号仍须在正文首次出现处解释**；
- 检查：全文是否一致？单位是否标注？上下标是否规范？是否存在同名不同义？

### 第五章 模型建立与求解

篇幅核心，通常占全文最大比重。

- 推导要**可跟随**，不要跳步；
- 优化模型在推导结束后应有明确总结句（如“综上所述，模型为”），并**紧接完整的目标函数、约束条件与变量域**；
- 关键参数必须说明**来源**（数据估计、文献引用、实验标定），不得凭空给出；
- 结果必须有**对照基线**与**独立验证**，不能只报最优值；
- 必须包含**灵敏度分析或稳健性讨论**。

### 第六章 模型总结

优点与缺点都要写，且**缺点必须是真实存在的**，并给出改进方向。空泛的“模型具有较好的推广性”不加分。

### 参考文献与附录

- 正文引用与文末文献**双向对应**，不能有孤儿条目；
- 中文赛题建议包含**真实、相关的中文文献**；
- 附录按功能分板块（支撑材料清单 / 软件环境 / 核心代码 / 补充结果）；
- **每一问的核心复现代码**应完整，但不需要粘贴全部工程代码。

### AI 工具使用披露

研究生赛明确：**允许使用 AI 产品，但仅作辅助工具，不能代替独立思考与答题主体工作**；所有引用文献与**引用程序（含 AI 产品）**须注明来源。

因此披露材料必须：

- **如实**——真实记录用了什么工具、用在哪一环；
- **完整**——覆盖所有使用环节，含代码生成与文字润色；
- **可核查**——说明生成内容如何被人工修改与验证；
- **匿名**——不得出现单位、参赛人员姓名、队伍编号；
- **边界清晰**——明确哪些工作是队伍独立完成的主体工作。

工具：`hwb-ai-usage-disclosure`（生成与自查）、`hwb-paper-aigc-auditor`（痕迹审计）

## 五、使用说明

- 本目录说明仅供写作、训练与自查参考，**不代表竞赛官方统一模板**；
- 涉及竞赛规则、AI 披露、页数与附件要求时，**以当届组委会最新正式文件为准**；
- 不得根据说明虚构数据来源、程序结果或 AI 使用记录；
- 提交前应清除单位、姓名、指导教师、队伍编号、联系方式、本地绝对路径与文档作者元数据。
