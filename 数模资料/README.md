# 数模资料

本目录是 `hwb-math-modeling-skills` 的**赛事语料与规则资料区**，用于支撑全部 `hwb-...` Skill 的规则判断、题型分析、评审校准与写作指导。

全部内容以本地归档的**历年优秀论文与赛题**为核心数据来源，并与官方公开文件交叉核对；凡未核实的数字一律留空或标注「待核实」，不作编造。

> **关于路径占位符**：本仓库只提交**文本索引与文档**，不包含任何赛题、论文或数据集的原始文件（版权与体积原因，详见各子目录说明）。全部索引中的 `<本地归档根目录>` 是一个占位符，请替换为你本机实际存放归档资料的目录（例如 `D:/<归档目录>`）后再使用。索引里的相对路径均以该目录为根。

## 七、使用说明

- 资料仅供**写作、训练与自查**参考；`论文模板/` 目录**不提供、也不伪造官方模板文件**，请从官方平台获取当届附件。
- 涉及竞赛规则、奖项比例、AI 工具披露、论文页数与支撑材料要求时，以**当届组委会最新正式文件**为准。
- 使用模板后仍需根据具体赛题、真实模型、代码与结果改写，不应保留示例内容。
- 参考文献、数据来源、程序结果与 AI 使用记录**必须真实**，不得依据模板虚构。
- 提交前应清除单位、姓名、指导教师、队伍编号、联系方式、本地绝对路径与文档作者元数据。

## 八、收录原则

- 仅收录公开资料、自主整理内容或已获得传播授权的材料；
- 不上传未公开赛题、未公开参赛论文或包含个人身份信息的文件；
- 不上传 API Key、Token、账号密码及其他敏感内容；
- **不提供任何未经核实的统计数据**：凡未公开核实的字段一律留空、写 `NA` 或标注「待核实」；
- 新增或替换文件时，应同步更新本索引中的文件名称、用途与适用范围。
