# 数据集说明

本目录说明本地归档的**赛题配套数据集**结构、字段与处理要点。

当前归档的数据集为 **2025 年（第二十二届）E 题“高速列车轴承智能故障诊断问题”**的配套数据，是本地语料中**唯一“赛题 + 数据 + 优秀论文”三者齐全**的题目，最适合做端到端复现训练。

## 一、归档位置与规模

| 项目 | 内容 |
|---|---|
| 本地根目录 | `<本地归档根目录>/数据集/` |
| 压缩包 | `<本地归档根目录>/数据集.zip`（约 356 MB 解压后） |
| 文件总数 | **177 个 `.mat` 文件** |
| 源域（有标签） | `源域数据集\` — **161 个文件** |
| 目标域（无标签） | `目标域数据集\` — **16 个文件** |
| 文件格式 | MATLAB 5.0 MAT-file（v5，`PCWIN64` 平台），数值块为 **zlib 压缩**，工作区变量均为 **double 列向量** |

> 结构化索引见 [`../_索引数据/数据集文件索引.csv`](../_索引数据/数据集文件索引.csv)；
> 逐文件变量名与维度见 [`../_索引数据/数据集变量结构.json`](../_索引数据/数据集变量结构.json)。

## 二、目录结构

```text
数据集\数据集\
├── 源域数据集\
│   ├── 12kHz_DE_data\          （驱动端，12 kHz 采样）
│   │   ├── B\{0007,0014,0021,0028}\     滚动体故障
│   │   ├── IR\{0007,0014,0021,0028}\    内圈故障
│   │   └── OR\{Centered,Opposite,Orthogonal}\{0007,0014,0021,0028}\  外圈故障
│   ├── 12kHz_FE_data\          （风扇端，12 kHz 采样，结构同上但组合较少）
│   ├── 48kHz_DE_data\          （驱动端，48 kHz 采样）
│   └── 48kHz_Normal_data\      （正常基线，4 个文件）
└── 目标域数据集\
    ├── A.mat … P.mat           （16 个文件，无标签）
```

## 三、命名规则

### 3.1 故障类别

| 代号 | 含义 |
|---|---|
| `B` | Ball — 滚动体故障 |
| `IR` | Inner Race — 内圈故障 |
| `OR` | Outer Race — 外圈故障 |
| `N` | Normal — 正常（无故障基线） |

### 3.2 外圈故障位置（`OR` 下的三个子目录）

| 代号 | 含义 |
|---|---|
| `Centered` | 外圈故障位于承载区中心（文件名标记 `@6`） |
| `Opposite` | 外圈故障位于承载区对面（文件名标记 `@12`） |
| `Orthogonal` | 外圈故障位于承载区正交位置（文件名标记 `@3`） |

### 3.3 故障直径

以**千分之一英寸**为单位，四位数字表示：

| 代号 | 实际直径 |
|---|---|
| `0007` | 0.007 英寸 |
| `0014` | 0.014 英寸 |
| `0021` | 0.021 英寸 |
| `0028` | 0.028 英寸 |

### 3.4 文件名中的载次

文件名末位数字 `_0` / `_1` / `_2` / `_3` 对应不同的**电机负载工况**（0—3 HP），转速随负载升高而下降。部分文件在括号中直接标注了转速，例如 `B028_3_(1730rpm).mat`。

**示例解读**：`OR007@6_2.mat` = 外圈故障、故障直径 0.007 英寸、位于承载区中心、负载工况 2。

## 四、工作区变量

### 4.1 源域数据（有标签）

变量名形如 `X<编号>_DE_time` 或 `X<编号>_FE_time`：

| 变量后缀 | 含义 |
|---|---|
| `_DE_time` | Drive End — 驱动端加速度振动信号 |
| `_FE_time` | Fan End — 风扇端加速度振动信号 |

部分文件另含 `X<编号>RPM` 变量，记录该次采样的**电机转速**（例如 `X309RPM`、`X213RPM`）。

**实测示例**：

| 文件 | 工作区变量 | 维度 |
|---|---|---|
| `12kHz_DE_data\B\0007\B007_0.mat` | `X118_DE_time` | 96000 × 1 |
| `12kHz_DE_data\B\0007\B007_1.mat` | `X119_DE_time` | 96000 × 1 |
| `12kHz_DE_data\IR\0007\IR007_0.mat` | `X105_DE_time` | 96000 × 1 |
| `12kHz_DE_data\OR\Centered\0007\OR007@6_0.mat` | `X130_DE_time`、`X130_FE_time` | 96000 × 1 |
| `12kHz_DE_data\B\0028\B028_3_(1730rpm).mat` | `X051_DE_time` | 96000 × 1 |
| `48kHz_Normal_data\N_0.mat` | `X097_DE_time` | 243938 × 1 |

### 4.2 采样长度分布（源域 161 个文件）

| 样本点数 | 文件数 | 说明 |
|---|---|---|
| 96000 | 115 | 主要长度 |
| 192000 | 53 | 48 kHz 采样的常见长度 |
| 384000 | 3 | 长记录 |
| 243938 | 1 | 正常基线（`N_0.mat`） |
| 121168 / 124602 / 128663 / 129969 / 130549 | 各 1—3 | 短记录，逐文件核对 |
| 63788 | 1 | 最短记录 |

> ⚠️ **长度不统一**是本题第一个真实工程难点：直接堆叠成长方阵会失败，必须做**分帧截断或重叠采样**统一长度。

### 4.3 目标域数据（无标签）

16 个文件 `A.mat`—`P.mat`，每个文件含**一个与文件同名的 double 列向量**：

| 文件 | 工作区变量 | 维度 |
|---|---|---|
| `A.mat` | `A` | 256000 × 1 |
| `B.mat` | `B` | 256000 × 1 |
| … | … | … |
| `P.mat` | `P` | 256000 × 1 |

**关键特征**：
- 目标域**没有任何标签**，只有振动信号本身 —— 这正是本题“无监督迁移学习”设定的由来；
- 每个文件 256000 采样点，长度统一；
- 变量名即文件名字母，**没有** `_DE_time` 之类的端别信息，也无 RPM 变量。

## 五、本题的建模要点

结合 2025 E 题优秀论文（见 [`../优秀论文索引/优秀论文阅读指南.md`](../优秀论文索引/优秀论文阅读指南.md)），本题的典型路线与坑点：

### 5.1 核心设定

**源域有标签、目标域无标签**，且两者分布存在差异 —— 这是一个标准的**无监督域适应（Unsupervised Domain Adaptation）**问题。

### 5.2 典型处理链路

```text
读取 .mat（注意 zlib 压缩，需 scipy.io.loadmat 或 h5py 兼容读取）
  ↓
统一长度（分帧 / 重叠采样 / 截断）
  ↓
信号预处理（去噪、归一化、去直流分量）
  ↓
特征提取（时域统计量、频域谱、时频域 STFT/小波）
  ↓
源域训练分类器（CWRU 源域标签 → B/IR/OR 及直径、位置多分类）
  ↓
域适应（对抗对齐、MMD、伪标签自训练、迁移学习）
  ↓
目标域预测（A—P 十六个文件的故障类别）
```

### 5.3 已识别的坑点

| 坑点 | 说明 |
|---|---|
| **采样长度不统一** | 源域从 63788 到 384000 不等，必须处理 |
| **采样率混杂** | 12 kHz 与 48 kHz 混在同一源域目录树中，直接混用会引入频率轴错位 |
| **负载工况不平衡** | 某些故障组合只有 1 个工况样本（如 `12kHz_FE_data\OR\Opposite` 仅有 `0007`） |
| **端别不一致** | DE 与 FE 通道信号不同，混用需说明理由 |
| **标签层级多** | 类别可细分为“故障类型 × 直径 × 位置”三级，定义清楚分类粒度是得分关键 |
| **目标域无标注** | 无法直接计算目标域准确率，必须设计**域内一致性验证**或**源域留出验证** |
| **`.mat` 为压缩存储** | 部分工具直接读会失败，需确认读取库支持 v5 压缩格式 |

### 5.4 验证建议

- 在源域内部做**留出验证**或**跨工况验证**（如用负载 0—2 训练、负载 3 测试），模拟域偏移；
- 用**域间分布距离指标**（如 MMD、A-distance）作为域适应的间接证据；
- 报告目标域预测结果的**分布均衡性**与**置信度分布**，而非仅给出标签；
- 明确说明哪些结论是**有证据的**，哪些是**推断的**——研究生赛评审非常看重这一区分。

## 六、读取示例

```python
import scipy.io as sio
import numpy as np

# 源域：驱动端滚动体故障，0.007 英寸，负载工况 0
m = sio.loadmat(r"<本地归档根目录>/数据集/源域数据集/12kHz_DE_data/B/0007/B007_0.mat")
sig = m["X118_DE_time"].ravel()      # 96000 点
print(sig.shape, sig.dtype)

# 目标域：A 文件
t = sio.loadmat(r"<本地归档根目录>/数据集/目标域数据集/A.mat")
tgt = t["A"].ravel()                  # 256000 点
print(tgt.shape, tgt.dtype)
```

> 若环境无 `scipy`，可用 `h5py` 检查是否为 v7.3 格式；本数据集实测为 **v5 压缩格式**，`scipy.io.loadmat` 可直接读取。
> 变量名不固定（如 `X118` 而非 `X097`），**不要写死变量名**，应遍历非 `__` 开头的键。
