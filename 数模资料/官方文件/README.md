# 官方文件

本目录收录**“华为杯”中国研究生数学建模竞赛**的赛事口径文件，是本仓库全部 `hwb-...` Skill 的规则依据。

> ⚠️ **本仓库不存储官方原件。** 组委会每届发布的《竞赛通知》《论文格式规范》《论文模板》《下载试题及上传论文操作手册》只能在官方平台获取。本目录的文档是**基于官方公开信息整理的口径说明**，用于给 Skill 提供稳定、可复用的判断依据。

## 本目录文件

| 文件 | 定位 | 主要用途 |
|---|---|---|
| [`华为杯赛事事实基准.md`](华为杯赛事事实基准.md) | **唯一事实基准（source of truth）** | 赛事身份与关键参数速查、奖项比例上限、特色荣誉、论文与提交硬约束、AI 使用政策、2020—2025 真题清单、常见误记纠正 |
| [`华为杯赛事规则总览.md`](华为杯赛事规则总览.md) | 规则叙述版 | 赛事身份表、历届承办与规模、报名与评奖公示流程、论文格式与提交时序的完整叙述 |

## 口径与优先级

1. **当届官方文件优先**：本目录内容与当届官方文件冲突时，一律以当届官方《竞赛通知》《论文格式规范》《论文模板》《操作手册》为准。
2. **不编造条款**：凡官方未公开明确的规定，一律标注「以当年《竞赛通知》为准」或「待核实」，不得凭印象补全。
3. **不做版本推断**：不同届次可能调整页数、附件大小、提交时段等要求，**不得用往届规则套用当届**。
4. **区分赛事**：本赛事为**研究生层次**竞赛；本科层次的“高教社杯全国大学生数学建模竞赛”是**另一项赛事**，赛题数量、论文格式、评奖比例、评审组织方式均不同，规则**不可互相套用**。

## 更新流程

1. 每届赛事结束后，核对官方《竞赛通知》《论文格式规范》是否有条款调整；
2. 更新 `华为杯赛事事实基准.md` 中受影响的小节，并在 `CHANGELOG.md` 记录变更；
3. 同步检查 `hwb-...` 各 Skill 中引用了旧口径的表述；
4. 已核实的历史数据继续保留；未核实字段维持「待核实」状态。
