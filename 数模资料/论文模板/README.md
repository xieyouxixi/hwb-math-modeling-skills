# 论文模板与排版硬约束

本目录说明“华为杯”论文模板的**获取方式**与**排版硬约束清单**。

> ⚠️ **本仓库不提供、也不伪造官方模板文件。** 竞赛组委会每届发布《论文模板》《论文格式规范》《下载试题及上传论文操作手册》三份附件，只能在官方平台获取。任何声称“官方模板”的第三方文件都存在版本过期风险。

---

## 一、官方模板获取路径

1. 访问 **中国研究生创新实践系列大赛管理平台**：<https://cpipc.acge.org.cn/>
2. 注册 / 登录 → 进入**个人中心**
3. 选择 **我的赛事** → 找到当届“中国研究生数学建模竞赛”
4. 在赛事通知中下载当届附件：
   - 《下载试题及上传论文操作手册》
   - 《论文格式规范》
   - 《论文模板》（含封皮页与统一摘要页）

> 每年赛前，各研究生培养单位的研究生院/数学学院通常也会转发这三份附件，可同时向本院系确认。

**另一条辅助渠道**：竞赛期间官方答疑论坛为**数学建模网** <https://www.shumo.com>。该论坛仅用于赛题文字理解提问，不提供模板下载。

## 二、论文结构（按官方模板顺序）

```text
第 1 页    封皮页
           ├─ 官方模板自带，不可删除
           ├─ 含团队相关信息
           └─ 含 4 个图标，不可替换
第 2 页起  摘要页
           ├─ 使用官方「统一摘要页」
           ├─ 内容不超过 2 页
           └─ 须含：建模思路、主要方法、模型、结果与结论、创新点
其后       正文
           ├─ 严禁出现目录
           └─ 按模板章节顺序组织
文末       参考文献
           附录
另附       支撑材料 / 附件压缩包（题号+队伍编号.rar，≤50 MB，可选）
```

### 3.4 提交时序（三段式，分时段进行）

| # | 步骤 | 说明 | 核对 |
|---|---|---|---|
| 29 | 第 1 步 | 提交论文 PDF 的 **MD5 识别码** | ☐ |
| 30 | — | ⚠️ **提交 MD5 后论文禁止修改**，否则无法成功上传 | ☐ |
| 31 | 第 2 步 | 提交**论文 PDF 文件**（无需上传其他附件） | ☐ |
| 32 | — | 上传成功后须点击【提交】按钮，后台才能收到 | ☐ |

## 四、常见模板误用

| 误用 | 后果 | 正确做法 |
|---|---|---|
| 用 CUMCM（本科国赛）模板 | 无封皮页、摘要页格式不符 | 只用研究生赛官方模板 |
| 使用往年模板 | 图标、摘要页可能已改版 | 每届重新下载当届模板 |
| 自行美化封皮页 / 替换图标 | 视为不合规 | 封皮页保持官方原样 |
| 在正文加目录 | 违反官方明文规定 | 一律不加目录 |
| 摘要写成 3 页以上 | 超出官方限制 | 压缩到 2 页内 |
| 首页也做匿名处理 | 丢失团队信息，可能无法关联参赛队 | 首页须保留团队信息 |
| 只在首页写身份信息，附件里却出现 | 违规风险 | 附件同样匿名化 |
| 提交 MD5 后才修改论文 | 论文无法上传 | 定稿后再提交 MD5 |
