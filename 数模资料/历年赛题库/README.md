# 历年赛题库

“华为杯”中国研究生数学建模竞赛自 2019 年起稳定为 **A、B、C、D、E、F 六题制**。本目录汇总历年赛题名称、题型定位、难度分布与本地归档位置，用于读题训练、选题参考与题型规律分析。

## 归档使用提示

1. **解压工具**：`.rar` 需 WinRAR/7-Zip；`.7z` 需 7-Zip；部分压缩包有解压密码，密码通常由组委会在赛期公布（2024 年 E 题数据解压密码与赛题解压密码相同）。
2. **大附件提示**：2023 F 题、2024 D 题与 E 题的赛题包体量很大（GB 级），解压前确认磁盘空间。
3. **赛题包结构**：通常包含题目 PDF/DOCX、附件数据、以及（部分年份）数据说明与更正说明。读题时务必一并阅读**更正说明**，它可能改变题目条件。
4. **版权提示**：赛题与附件版权归主办方所有，仅供学习研究使用，不得用于商业用途或二次分发。

## 六题制题型规律（经验归纳，非官方）

> ⚠️ 以下为基于 2020—2025 年赛题的经验归纳，**题号含义逐届变化**，仅用于备赛训练与题型感知，**不得**作为当届选题的预设判断。当届赛题始终优先。

| 题号 | 常见方向 | 典型题型 |
|---|---|---|
| A | 工程物理、器件机理、调度与资源分配 | 组合优化、离散事件调度、机理+优化 |
| B | 常为**华为企业赛题**；通信、网络、信息化 | 数据驱动预测建模、系统性能建模、机器学习 |
| C | 数据驱动建模；材料/器件、医学诊疗 | 特征工程 + 回归/分类、物理约束建模 |
| D | 空间地理、多源数据融合、大尺度系统 | 时空数据分析、GIS、多源融合 |
| E | 信号处理、故障诊断、交通与运载工程 | 信号特征提取、迁移学习、交通流建模 |
| F | 机理建模、结构力学、评价与量化 | 微分方程/力学建模、多指标评价 |

**关于华为赛题**：历年华为赛题多落在 **B 题**（如 2024 年 B 题“WLAN 组网中网络吞吐量建模”明确标注为华为题目）。选择华为赛题的队伍可**同时参评华为专项奖**（一等奖 4 队、二等奖 12 队，奖金与常规奖项**累加**）。选报前应评估队伍在通信/网络/数据驱动方向的实际能力。

## 选题建议

1. **看数据可得性**：优先选择附件数据完整、字段说明清晰的题目；数据缺失会直接导致建模无法落地。
2. **看能力匹配**：六题通常覆盖优化、数据驱动、机理建模三条主线，选择队伍最熟练的主线。
3. **看华为专项奖**：若队伍在通信/网络/数据驱动方向有积累，评估是否值得冲华为赛题以叠加专项奖。
4. **看时间预算**：赛期约 4 天，题目若需要大量数据预处理或高计算量仿真，要预留充足求解时间。
5. **不要在赛道间反复横跳**：确定题目后应尽快冻结选择，把时间投入建模与写作。
