# 优秀论文索引

本目录汇总本地归档的 **2020—2025 年**中国研究生数学建模竞赛优秀论文，提供结构化清单、题号分布与阅读路径建议。

## 本目录文件

| 文件 | 粒度 | 内容 |
|---|---|---|
| [`优秀论文索引.csv`](优秀论文索引.csv) | **篇** | 论文级索引（229 行）：年份、题号、论文/队伍编号、培养单位代码（由编号解析）、来源 |
| [`优秀论文阅读指南.md`](优秀论文阅读指南.md) | — | 论文清单、题号分布、分阶段阅读方法与精读建议 |
| [`../_索引数据/本地优秀论文文件索引.csv`](../_索引数据/本地优秀论文文件索引.csv) | **文件** | 文件级索引（159 行）：年份、届次、题号、文件名、本地相对路径、大小、是否压缩包、备注 |

> 两套索引粒度不同、并不矛盾：**篇级**索引把 2020 / 2022 年的压缩包拆到篇（共 229 篇）；**文件级**索引按磁盘上真实存在的文件计数（12 个 zip 各算 1 条，故为 159 条）。

## 使用提示

1. **2020 与 2022 年需先解压**：这两个年份以分题压缩包形式归档，解压后得到该题的论文合集。
2. **2021 年目录名含空格**：`6.16 数模论文`，在命令行中引用时需加引号。
3. **文件名即队伍编号**：2021、2023、2024 年的 PDF 文件名形如 `A24102940057.pdf`，首字母为题号，可据此批量筛选。
4. **版权提示**：优秀论文版权归原作者与主办方所有，仅供个人学习研究使用，不得用于商业用途或二次分发。
