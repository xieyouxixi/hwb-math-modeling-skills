> 覆盖 2020—2025 年优秀论文共 **159 个条目**。本文档给出完整清单与分阶段阅读方法。
> 完整机器可读索引见 `../_索引数据/本地优秀论文文件索引.csv`。

## 一、分阶段阅读方法

备赛期阅读优秀论文，最容易犯的错误是“从第一篇读到最后”——既耗时又记不住。建议按下面三个阶段推进：

### 阶段 1：结构感知（每篇 15—20 分钟，只需读 3—5 篇）

目标：建立“一篇高分论文长什么样”的整体印象。

- 只读 **封皮页、摘要页、目录结构（章节标题序列）**，不读正文细节；
- 记录：摘要用了几段？每段在说什么？章节顺序是什么？各章大致页数占比？
- 重点关注摘要是否包含官方要求的五要素：**建模思路、主要方法、模型、结果与结论、创新点**。

对应自查工具：`hwb-abstract-checker`、`hwb-paper-format-checker`

### 阶段 2：同题精读（同题 3—5 篇对照，共 2—3 小时）

目标：建立“同一道题可以怎么解”的方法谱系。

- 选定**一道与你队伍方向接近的往年赛题**；
- 把该题的全部优秀论文放在一起对照读；
- 画一张对照表：

| 对比维度 | 论文 A | 论文 B | 论文 C |
|---|---|---|---|
| 问题抽象方式 | | | |
| 核心模型 | | | |
| 数据处理路线 | | | |
| 求解算法 | | | |
| 验证/灵敏度做法 | | | |
| 创新点落脚处 | | | |

- 关键收获不是“背下某个模型”，而是**看到同一问题的多条合法解法，并理解各自的取舍**。

### 阶段 3：题型横向（跨年跨题，选 5—8 篇）

目标：形成题型直觉，为当届选题与建模服务。

- 按题型分组精读：优化调度类、数据驱动预测类、机理建模类、评价决策类；
- 每类抽 1—2 篇，重点看**问题分析章节如何把实际问题翻译成数学问题**；
- 关注这些通用动作：假设怎么提、符号怎么定、模型怎么求解、结果怎么验证。

对应自查工具：`hwb-problem-analysis-checker`、`hwb-model-assumption-checker`、`hwb-symbol-notation-checker`

## 七、精读清单建议（时间有限时的最优 8 篇）

若只读 8 篇，建议按此优先序：

| 优先级 | 论文 | 理由 |
|---|---|---|
| 1 | 2021 年任一篇“数模之星提名奖” | 最高质量档，学结构 |
| 2 | 2021 年另一篇“数模之星提名奖” | 对照学摘要与创新点写法 |
| 3 | 2025 E 题-基于迁移学习的高速列车轴承故障诊断研究 | 与你方向可能接近，且有配套数据 |
| 4 | 2025 E 题-无监督迁移学习下的轴承故障诊断建模与优化 | 同题对照，学方法取舍 |
| 5 | 2024 B 题任一篇（华为赛题） | 学企业赛题的数据驱动路线 |
| 6 | 2024 C 题任一篇 | 学“数据驱动 + 物理机理”结合写法 |
| 7 | 2023 F 题任一篇（强对流降水临近预报） | 学复杂时空预测的组织方式 |
| 8 | 2025 F 题-多模态数据融合视角下江南古典园林美学特征量化建模研究 | 学多指标评价与量化建模 |
