# 官方评阅细则与评分要点

本目录汇总“华为杯”中国研究生数学建模竞赛的**评审组织方式、关注点与常见失分点**，是 `hwb-review-paper` 制定评分细则、以及各章节自查类 Skill 判断扣分项的依据。

> ⚠️ **重要边界**：竞赛组委会**不公开发布逐题评分细则**。本文档是基于历届《开赛通知》《论文格式规范》《评阅概述》及专家委员会公开表述归纳的**评审关注点**，不是官方评分表。任何具体的分值分配、扣分幅度均为本项目的内部方法，**不代表官方标准**。

---

## 一、评审组织方式

| 环节 | 内容 |
|---|---|
| 形式审查 | 论文格式、匿名性、命名、页数、附件合规性 |
| 网上评审 | 由专家委员会成员与特邀专家进行，历时约 1 个月 |
| 集中评审 | 144 位量级专家为期数天，对网上评审入围论文复核 |
| 查重 | 专家委员会对全部论文查重；重复率高于阈值一般直接判定为“违规论文”，必要时人工判断 |

**规模参考（2025 年第二十二届）**：网上与集中评审共动用专家委员会全体委员与特邀专家 944 人，历时近两个月。

## 二、十大评审关注点

以下是研究生赛论文评审的关注焦点，也是 `hwb-review-paper` 建立评分维度的来源。

| 序号 | 关注点 | 具体含义 | 对应自查工具 |
|---|---|---|---|
| 1 | **问题理解的准确性** | 是否真正读懂题目条件、数据口径与交付要求；有无漏读小问、误解定义 | `hwb-problem-translator`、`hwb-problem-restatement` |
| 2 | **数学抽象的层次** | 是否把实际问题转化为恰当的数学问题，而非停留在数据搬运或现象描述 | `hwb-problem-analysis-checker`、`hwb-modeling-ideas` |
| 3 | **模型选择的必要性** | 为什么用这个模型？更简单的模型为何不足？复杂度和数据是否支撑 | `hwb-model-dictionary`、`hwb-model-solution-checker` |
| 4 | **假设、参数与约束的来源** | 关键参数是否有依据（数据估计/文献/标定），假设是否被后文真正使用 | `hwb-model-assumption-checker` |
| 5 | **推理链与跨问题联动** | 六问是否构成一条完整研究链，而非六个独立片段 | `hwb-problem-analysis-checker`、`hwb-model-solution-checker` |
| 6 | **求解的真实性与可复现性** | 结果是否由所给模型与数据真实求得；附录核心代码是否支持复现 | `hwb-model-solution-checker`、`hwb-reference-appendix-checker` |
| 7 | **检验、反证与稳健性** | 是否有独立的验证环节、对照基线、灵敏度分析，而非只报最优值 | `hwb-model-solution-checker` |
| 8 | **洞察与创新** | 是否有超出常规套路的建模视角或结论 | `hwb-modeling-ideas`、`hwb-review-paper` |
| 9 | **论文规范与可读性** | 格式、匿名性、摘要可独立阅读、图表质量、公式与符号闭环 | `hwb-paper-format-checker`、`hwb-abstract-checker`、`hwb-symbol-notation-checker` |
| 10 | **学术诚信** | 引用是否规范、AI 使用是否如实披露、程序是否为原创或已标注来源 | `hwb-ai-usage-disclosure`、`hwb-paper-aigc-auditor` |

## 三、常见失分点（按严重度排序）

### P0 — 资格级风险（可能导致论文无效或判违规）

| 失分点 | 说明 |
|---|---|
| 非首页出现单位、参赛人员姓名、队伍编号 | 官方明文：除首页外出现即**论文无效** |
| 删除或替换封皮页的 4 个图标 | 官方明文：封皮页不可删除、图标不可替换 |
| 论文中出现目录 | 官方明文：论文中严禁出现目录 |
| 论文非 PDF 或文件命名不合规 | 必须为 PDF，且命名为 `题号+队伍编号` |
| 查重重复率超阈值 | 一般直接判定为违规论文 |
| 引用他人程序未标注来源 | 发现程序雷同按抄袭认定为违规论文 |
| AI 使用未如实披露 | 所有引用程序（含 AI 产品）均须按规定注明来源 |

### P1 — 严重内容缺陷

| 失分点 | 说明 |
|---|---|
| 漏读小问或误解任务 | 某问整体未作答或答非所问 |
| 结果无来源 | 出现结论性数值但正文没有对应的求解过程 |
| 关键参数凭空给出 | 参数无数据估计、无文献引用、无标定依据 |
| 无任何验证环节 | 只报最优值，没有对照基线、没有灵敏度分析 |
| 跨问断裂 | 六问互不相关，看不出研究链 |
| 公式或符号未定义 | 正文出现无法解读的公式或不明的符号 |

### P2 — 重要问题

| 失分点 | 说明 |
|---|---|
| 摘要不能独立阅读 | 缺五要素之一，或只讲做了什么不给结果 |
| 假设无效 | “假设数据可靠”这类无信息量假设 |
| 图仅堆积无解释 | 图表未被正文引出与解读 |
| 模型堆砌 | 罗列多个时髦模型但未说明必要性 |
| 参考文献与正文引用不对应 | 存在孤儿条目 |
| 中文情境论文缺中文文献 | 建议补充真实相关的中文来源 |

### P3 — 一般问题与优化建议

| 失分点 | 说明 |
|---|---|
| 排版不统一 | 字体字号混乱、图表编号不连续 |
| 结果表述空泛 | “效果良好”式表述代替具体数值 |
| 章节命名不规范 | 与官方模板章节名不一致 |
| 篇幅失衡 | 某一问挤占全文，关键问过短 |

## 四、评分维度参考框架

`hwb-review-paper` 采用 **100 分制**，并在每次评审时**按当届赛题重新分解任务、冻结评分细则**。参考框架：

| 板块 | 参考权重 | 说明 |
|---|---|---|
| 摘要与成果概括 | 10 | 五要素齐全、可独立阅读、有具体结果 |
| 论文规范与可读性 | 10 | 格式、匿名、图表、公式符号闭环 |
| **核心问题回答** | **75** | 按当届六问实际任务拆解，采用证据中心评分 |
| 全文整体性与应用价值 | 5 | 六问是否构成完整研究链、实际价值 |

核心 75 分再按七个**证据中心维度**分配（本项目方法，非官方）：

| 维度 | 参考权重 |
|---|---|
| 任务理解与数学抽象 | 12 |
| 模型选择的必要性 | 14 |
| 假设、参数与约束证据 | 12 |
| 推理链与跨问题联动 | 12 |
| 求解真实性与可复现性 | 10 |
| 检验、反证与稳健性 | 10 |
| 洞察、创新与实际价值 | 5 |

> 评分机制详见 `skills/综合评审与自我定位类/hwb-review-paper/references/` 下的 `rubric-construction.md`、`atomic-deduction-scoring.md`、`evidence-centered-scoring.md`。

## 五、获奖比例锚点

`hwb-review-paper` 的位次估计使用研究生赛**实际获奖比例**作为锚点：

| 奖项 | 2025 年实际比例 | 队数 |
|---|---|---|
| 一等奖 | 1.00% | 244 |
| 二等奖 | 12.66% | 3085 |
| 三等奖 | 19.82% | 4830 |
| **合计** | **33.48%** | **8159** |

章程上限：一等 ≤1.5%、二等 ≤13%、三等 ≤20%。

由此得到的关键阈值：

- **一等奖线** ≈ 前 **1.0%**
- **二等奖线** ≈ 前 **13.66%**（1.00% + 12.66%）
- **三等奖线** ≈ 前 **33.48%**

> 位次估计为**经验插值**，不代表官方名额，也不构成获奖承诺。
